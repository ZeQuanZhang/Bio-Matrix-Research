# Bio-Matrix v2

v2将条件矩阵记忆放进Transformer：输入通过相位地址选择一组节点，从块起点的状态联合读取，块末同时提交全部节点的内容与地址更新。它检验相位寻址和多节点协作能否改善远史检索，并记录与普通Transformer的实际成本差距。

v1、v1.1的源码、原始结果和检查点保留。v2采用新的块级更新规则，没有自由振荡、逐token矩阵递推、球壳扩散或运行时节点增生；旧机制的实现继续保存在旧版本中。

## 在PyCharm启动

本机使用项目 `.venv/bin/python`。新训练选择 **Bio-Matrix v2 原位训练**，已有任务的只读查看选择 **Bio-Matrix v2 原位进度**；两者使用根目录 `run_biomatrix_v2_console.py`，进度查看带 `--follow` 参数。原 `run_biomatrix_v2.py` 和 **Bio-Matrix v2** 配置保留，便于复现冻结协议。共享配置启用 **Emulate terminal**。默认 `DEVICE='auto'` 选择原生MPS，不连接旧A800。

首次运行先完成自检、冻结数据和主干身份校验，再训练。原位控制台每秒整体重绘，根据实际终端高度把12条进度排成多列，并按宽度截断阶段文本；13行终端可完整显示12条进度。只读查看不会暂停或重启训练，显示层未修改冻结的计算源码。验证时显示任务、条件及完成样本数。

入口顶部的默认值：

```python
MODE='train'                 # verify 只运行检查
DEVICE='auto'
CPT_TARGETS=131_072
PT_UPDATES=512
SEEDS='11,23,37'
RESUME=None                  # 原 results/v2/paired_... 目录
```

默认B4×512输入，每块64 token。每个条件/种子先做64次自然文本CPT更新，再做512次答案监督PT更新；共576次优化更新。完成同一训练种子的四个条件，再进入下一个种子，默认12条运行。

CLI短程检查示例：

```bash
.venv/bin/python run_biomatrix_v2.py --mode verify
.venv/bin/python run_biomatrix_v2.py --device mps --seeds 11 --cpt-tokens 2048 --pt-updates 2 --validation-windows 8
```

修改预算请使用新结果目录。正常停止请求在优化边界保存；PyCharm强制杀进程可恢复至最后检查点，未保存的更新不计入恢复进度。

## 四个配对条件

| 条件 | 结构 | 原文注意力窗口 | 参数量 |
|---|---|---:|---:|
| `trans_local` | 普通Transformer，扩大标准FFN匹配参数量 | 128 | 395,256 |
| `trans_full` | 同一Transformer，保留整个采样窗 | 512 | 395,256 |
| `v2_static` | 相位条件读取＋块并行内容写入，运行态地址固定 | 128＋矩阵记忆 | 395,186 |
| `v2_dynamic` | 内容与运行态相位地址共同更新 | 128＋矩阵记忆 | 395,186 |

**四组都全量训练Transformer主干。** v2同时训练内容读写、相位路由与地址锚点，动态地址组还训练运行态地址步长；固定地址控制不使用该步长。每组来自同一个已训练的词表4096、宽56、2层4头主干；Transformer把FFN宽度272扩为620，新通道输出初始化为0，保留原主干初始函数。两Transformer逐tensor共享初始化；两v2逐tensor共享初始化。参数差70，约0.018%。

同一种子的输入、答案mask、优化器、阶段预算与采样顺序相同；不同种子的训练采样与随机初始化独立变化。固定验证样本跨条件/种子共用。AdamW、lr3e-4、权重衰减0.01、梯度裁剪1，阶段分别调度学习率。两阶段都使用标注CE，未使用v1.1的小型QA教师KD。

`trans_local`提供相同局部窗口下的比较；`trans_full`提供可直接读取原文证据的较强对照，其显式KV预算更大。Transformer训练时一次计算整个采样序列，v2按8个块递推，计时不强迫Transformer沿用v2的分块调度。

## 相位、内容与排布的更新

每层32个固定节点、4头、14维内容矩阵、8个相位频带。运行态含节点内容M、单位圆地址P，以及自由方向矩阵F。读写使用同一套相位匹配；节点地址可以组成重叠的查询相关组合。

当前块的表示先经过因果局部注意力，再用共享地址投影得到条件向量k；sin/cos特征与全部节点旧地址比较，得到softmax关联g。所有token/节点一起计算，没有节点循环或token写入循环。

联合预测为 `prediction_t = Σ_j g_tj M_j k_t`；写入误差为 `value_t − prediction_t`。各节点从这个共同误差获得自己的加权修正，承担联合求解的贡献。块内只累计固定尺寸的充分统计：

```text
mass_j  = Σ_t g_tj
cross_j = Σ_t g_tj (value_t − prediction_t) k_tᵀ
gram_j  = Σ_t g_tj k_t k_tᵀ
phase_j = Σ_t g_tj phase(k_t)
```

内容更新用加权平均误差、可学习步长、显式保持/遗忘和F方向预条件；每块一次范数限制。F通过有界Gram更新抑制已经占用的方向，作为近似容量统计；它没有精确判定方程组满秩，也没有硬扩节点。

动态地址使用同一g加权的相位目标，小步移动并保留锚点约束，然后归一化到单位圆；固定地址组只关闭这一运行态移动，锚点本身仍可通过训练学习。地址不按时间自由旋转。内容与地址更新均从同一份旧快照计算，在块边界同时生效。

一块内新内容到下一块才进入长期读取，块内信息由局部注意力提供。训练和流式推理共享固定块时钟，Python调用切分不会定义新语义。状态大小由B/N/H/d/R固定，不随历史长度增长；代码内部不detach，答案梯度可以穿过前面的写入和地址调整。

## 数据与指标

复用冻结WikiText-2、训练集拟合的4096 BPE和官方SQuAD v1.1派生远史子任务。原始文件、准备文件、tokenizer与主干哈希必须匹配。SQuAD缓存位于 `data/v11/squad_remote256`，包含51,416条训练、2,553条验证、7,565条保留测试。

每条QA有384 token历史，标注答案证据完整位于最旧128之内，距回答超过两层128窗口的保守256感受野；提示与答案按整体规范BPE编码。历史裁剪使用公开标注位置，问题/答案来自官方人工标注。本任务单独报告NLL和首token命中，不采用完整SQuAD榜单EM/F1。

PT仅答案token参与损失，问题/上下文/EOS/PAD不监督。PT512次×B4为2,048次QA抽样，实际答案token数单独记录。进度单位为CPT有效目标＋PT输入槽，后者含PAD，不能解释成同样多的答案监督。

默认固定验证64条文本窗和64条QA，初始、CPT结束及PT第256步只做正常历史评分；固定最终预算做一轮完整干预，最终分数直接复用，不重复跑。比较答案NLL、首答案NLL/准确率、文本NLL/PPL、训练/验证时间与输入吞吐。

最终干预包括清空记忆、后缀禁读、无关记忆、打乱历史、全程禁读、替换有效感受野外的远史并重编码。直接状态干预保留相同当前KV；整条路径控制允许KV重新生成。全程禁读时也禁写，最终记忆状态被丢弃，已通过输出等价检查。完整窗口Transformer没有有效感受野外的该段远史，相关条件标为not_applicable。

## 保存、比较与恢复

每次新运行自动创建 `results/v2/paired_时间/`，拒绝覆盖旧目录：

- `protocol.json`、`source/`、`validation_sample.json`：版本、源文件/数据/主干哈希、参数、预算和固定样本。
- 每条运行的 `metrics.jsonl`、`validation.jsonl`、`initial_validation.json`、`cpt_validation.json`、`last.pt`、`result.json`：原始值、模型、优化器、阶段计数和全部采样/RNG状态。
- `registry.json`、`summary.json`：completed / aborted / failed / not_executed。
- `comparison.json`、`COMPARISON.md`：每种子的结果、均值/种子标准差、动态v2相对三个对照的配对差和耗时比。单种子标准差记为null。

将 `RESUME` 设为原目录，或传 `--resume results/v2/paired_...`。恢复要求代码、数据、预算、设备和PyTorch一致。已有进度但安全检查点或t=0验证缺失时拒绝静默重跑；失败的恢复预检单独留记录。独立训练窗口之间重置运行态，所以检查点不恢复上一条无关窗口的短期记忆。

正式默认队列由用户在PyCharm启动。开发验收只运行CPU测试、原生MPS数值/性能短测与有限预算入口配对；不提前宣布机制有效。最终测试集、充分训练上限和严格独立新情景控制尚未执行。
