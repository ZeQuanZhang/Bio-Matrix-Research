# v0.7 剩余范围与证据缺口

> 归档说明：本文保留写作时点的设计或状态。项目已停止v0.9后续训练；最新执行状态见[实验索引](../../../docs/RESULTS_INDEX.md)。公开副本不含权重与语料。

本表独立记录完整构想中仍开放的部分，供解释 core45 结果时使用。它不增加 core 的前置条件，不阻断已授权训练，也不把既有数学／工程验收改记为能力证据。实现公式和验收映射见 [V07_CONFORMANCE.md](../../../docs/V07_CONFORMANCE.md)；原始回归和历史快照保留在本目录。

## 尚未实现或只提供有限实现的方向

| 项目 | 已有实现及具体边界 | 完整构想中的位置 |
|---|---|---|
| 超过 8 步及自然语言中的语义反馈归因 | `Network.apply_feedback/feedback_frame` 只接受调用方明确提供的 lag，默认 H=8；越界拒绝，旧 slot 单次消费，参数更新后失效。普通 LM 使用自然 lag1。系统尚不解析一段自然语言究竟纠正哪次旧判断，也不精确关联任意时距反馈。 | v0.6 要求有限影响痕迹和有方向反馈；当前有界机制已经实现。开放语言中的对象识别及更长信用是进一步研究。 |
| 跨 session 自动巩固到永久参数 | `local_proposal/project_slow_update` 更新运行时 S；session 边界按协议清状态。`node_shape` 和基础映射通过训练期 AdamW 学习，未实现推理期间自动选择重要经验、把 S 转写为永久权重的独立巩固规则。保存检查点提供持久化，不自动决定知识的重要性。 | 原始完整构想第十三节将更慢巩固规则保留开放；不能把训练中的参数学习或手动保存称为已经实现自主终身巩固。 |
| 显式动态专家创建和稀疏执行 | 当前 `controls/weights` 形成状态依赖的有效路径，Fourier／相位耦合实际参与消息计算；但所有候选节点和边仍按规则张量计算。没有按临时专家群进行 Top-K dispatch、跳过未选群体的昂贵核或专家负载平衡。 | v0.6 明确将“额外群体聚类与动态专家创建”排除在主干之外；完整构想第十节的功能群体仍是开放研究方向。 |

JEPA、逐节点嵌入完整大模型、随历史增长的完整路径记录及还原任意长历史，属于用户明确排除或 v0.6 明确不采用的方向，不作为本次漏实现项目。优化器自演化属于原始构想第十四节的支线，本轮保留标准 AdamW，没有宣称实现该支线。

## 已有机制，但尚待真实训练和独立证据

| 项目 | 当前证据 | 尚不能据此宣布解决的内容 |
|---|---|---|
| 内部 P 的概率含义与校准 | `stationary_prior/joseph` 有 PSD、事件计数、平稳幅度界和数值回归；P 是节点矩阵回归中 key 方向的不确定性近似。token ECE 的边界分箱已修复。 | 内部 P 是否对应真实语义可靠性、观测噪声和相关信息源的可信后验，尚无校准真值与覆盖率实验。输出 ECE 不能替代内部概率校准。 |
| 真实历史依赖与无关后验隔离 | 同 targets 的 matched ABA、远史乱序频次控制、stateless、S／fast／credit 消融已经实现。稀有远处重复评分 mask 固定为 114 token／41 窗口；合成回归验证同 query 修订和正交内容保留。 | 异文档和无精确 token 匹配只是可观测代理，不是真实语义独立标签；远处重复也不保证每个目标必须使用历史。合成正交 query 的代数隔离不能直接推广到自然语义的近似重叠表示。 |
| 同情境规则变化与长期恢复 | 持续流训练包含 A→B→未见 A 后文，且 marked/unmarked 混合；固定自然变化 cue 有原文 span 清单；同 query 反向反馈、有限延迟及容量饱和有机制回归。 | cue 未被人工标成完整时变规则任务；自然文本训练后的规则修订速度、抗固执、恢复旧功能和新证据泛化仍须正式结果。A_B_A／B_B_A／shuffle／B_A_A 应联合解释，旧 return_cost 仍混合额外年龄。 |
| 动态功能专家是否涌现 | 不同历史、概率和相位能改变实际观测、路径和输出；断图、独立振荡与耦合对照可执行。 | 还没有多任务功能选择性、可复用群体、定向干预及跨种子复现证明“专家群”形成。相位整齐或活动分组本身不足以建立功能分工，稠密执行也未节省 FLOPs。 |
| 长期梯度、传播与反馈闭环稳定 | m／S／载波有范数预算，query 容量投影保留 S⊥，P 有平稳界，相位归一；局部直接读取 VJP 与有限差分一致；短程训练／恢复／编译路径已有工程检查。 | 状态依赖路由、控制、相位和持续可塑性组成的整网 Jacobian 与闭环长期增益没有全局稳定／收敛证明。默认 BPTT128 仍截断更长参数信用；局部数学方向正确不保证长流中的梯度有效、无串扰或损失单调下降。需检查长训曲线、梯度、裁剪、容量占用和反馈有效步长。 |
| 所有规模、多种子的真实收益 | core45 固定 32／128／512、五类模型、三种子；容量、J、断图、写入归一、信用范围等控制已有计划。CPU 测试、CUDA 短程和编译数值检查记录各自范围。 | 完整配对组、重复种子、泛化表现及计算成本未齐备前，不能预先宣布规模收益、超过标准 LLM 或训练已经收敛。按原始 result／protocol 和 completed 状态累计证据，窗口不能充当额外种子。 |

## 结果解释的边界

正式主能力证据使用冻结公开语料，合成只用于可解释机制回归。下一阶段应同时审视配对 NLL／PPL、同龄有序历史收益、无关干扰代价、内容消融、跨种子一致性和实测成本。源码、数据、编译模式或运行协议不同的结果分别标识；原始失败保留，包括编译逐坐标 hard probe 的失败，不能被全局梯度误差、余弦或优化轨迹通过覆盖。

以上各项区分了“明确不纳入本版”“有限实现”“有机制但待实证”。core45 可以继续按冻结协议执行，完成后再根据实际缺口选择下一轮验证。
