# Bio-Matrix 数据审计与修订

> 归档说明：本文保留写作时点的设计或状态。项目已停止v0.9后续训练；最新执行状态见[实验索引](RESULTS_INDEX.md)。公开副本不含权重与语料。

本记录对应数据 `lifelong-device-streams-v2`、配置 `v05-consolidation-2`。v0.4 源码和运行中的训练未修改。

## 发现的问题

最初 v0.5 repetition 将首条错误报告设为“真值+1”。对当前测试的16条颜色反事实轨迹（4个独立基础轨迹），仅对首条报告颜色减1便达到100%。答案平衡和隐藏字段隔离没有排除这条内容捷径。

最初 dev 与 test 都含较长延迟和 long，不能称为对模型选择完全隐藏的长度外推。重复声明前期还存在没有独立证据支持的真值请求，计入主损失会要求模型猜测不可知内容。

## 已修订

- 不可信声明独立于真值产生，并在四个反事实中保持完全相同；只改变可信历史与后续证据。所有可观察的声明前缀相同、真实答案四类平衡，任何仅依赖该前缀的确定性策略最多25%。
- 声明前期请求继续触发活动和资格迹，但不计入主损失；独立报告到达后的纠正和保持探针计分。
- 练习次数、地址报告顺序、干扰长度随机化。
- dev 延迟2/4/8，test 延迟16/32；long只进入test。
- dev每任务8个基础轨迹，共64个；test每任务32个，共288个。每个基础轨迹的四个颜色变化作为同一相关组处理。
- 主指标改为各任务末次查询的宏平均；dev按对应NLL选择检查点，保留所有可计分查询的微平均作为辅助结果。

修订后首条声明减1策略为32/128=25%，涉及32个独立基础轨迹。outlier末条不可信报告也固定于反事实组内，同一捷径为25%。

## 审计范围与实际结果

每版本抽查训练起始128组，即512条轨迹；核对该版本配置的全部固定dev/test。训练抽查只使用第一个训练种子，未声称遍历无限生成器或全部种子。

| 版本 | 训练抽查轨迹 | dev轨迹 | test轨迹 | 独立原始报告解释器检查的评分查询 | 标签不一致 |
|---|---:|---:|---:|---:|---:|
| v0.4 | 512 | 128 | 256 | 1,956 | 0 |
| v0.5数据v2 | 512 | 256 | 1,152 | 9,308 | 0 |

解释器根据先前的低噪可信原始报告建立关联账本，用审计器可见的世界标识分开情境，再计算查询答案；不读取生成器存储的truth字段。另行核对truth字段、目标平衡和模型输入字段。没有发现评分标签错配、隐藏答案字段进入模型或上述样本之间的精确流重复。

相同生成语法、相同算术操作和部分相同事件模板仍跨越训练/开发/测试。随机噪声、ID和线索会使精确哈希天然不同，因此哈希无重复不能证明任务结构完全独立。

## 来源质量与适用范围

可信报告按声明的Gaussian噪声生成。repetition专门包含自信但未经验证的声明；其声明标准差可能失准。本次实际均方误差约为声明方差的15.96倍。该字段应解释为来源声明，不可据此宣称概率后验已校准。

independent任务的当前直接观测基线为100%，用于检查无关历史污染；高分只表示通过这个对照。合成四类设备任务适合检验记忆、通信、巩固与纠错，公开中文任务和自然语言建模评测仍需单独执行。
