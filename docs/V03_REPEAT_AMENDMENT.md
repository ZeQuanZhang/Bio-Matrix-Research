在27次主规模扫描完成后，继续按任务书补齐P2/P3的三种子初筛。此补充遵循用户不限制训练时长的要求，不将单种子机制实验作为最终复现结果。

对全部45个初始P2/P3条件追加种子23、37，共90次2048更新：固定容量18次、训练匹配内部轮数36次、同度数切分/重连24次、CLEVR-SG12次。没有依据某个补充条件的最终测试分数筛选条件；全部条件获得相同追加种子。

模型、数据生成器、稀疏图、角色、初始相位、数据顺序规则、学习率选择和训练预算保持冻结。复用原训练函数，不修改已运行的四份核心训练源文件。新驱动只替换条件的训练种子和ID；每个种子仍使用70000+seed的数据种子，并保存配对指纹。

执行顺序：原81个条件完成 → 输入独立基线/干预/验证 → 保存首批报告、图和汇总快照 → 串行追加90个条件 → 重新验证、汇总。原始每条件结果和检查点不覆盖。首批报告保存在V03_INITIAL_SCREEN_FINDINGS.md，原始首轮matrix_lab结果继续保持不变。

动态/固定专家、流式协议、CoGenT及其他生物机制不混入本轮；任何未执行条件继续明确标记。精确条件列表和登记时间见results/v03/repeat_plan.json。
