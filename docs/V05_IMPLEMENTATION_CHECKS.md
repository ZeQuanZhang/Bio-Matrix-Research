## 已执行

- 32项测试通过：v0.5的21项机制/数据/恢复检查及v0.4的11项回归。日志：`results/v05/checks/unit_tests_accepted.txt`。
- CPU端到端短跑：message/full各2次优化更新，完整验证、7项干预、原子检查点、生命周期权重导出、原始概率和汇总生成完成。结果：`results/v05/smoke_data_v2_cpu/`。
- CPU规模剖析：32/128/512节点，两种读取路径，message/full，共12条件，每条件8个事件、实际反向与一次更新。
- 最大完整生命周期：512节点、batch4、72事件、每事件16内部轮次，事件级重计算、完整反传并更新一次，约88.37秒。检查进程累计RSS峰值约2.99GiB，不是隔离条件峰值，也不用于推算GPU耗时。
- 完整组合的保幅子步相对能量误差约1e-7。该性质只覆盖条件旋转载体，任务可读性与完整雅可比另测。
- 参数：full 5,138；message 5,177，差约0.76%。两组分配状态完全相同，节点数量改变实际状态容量。
- 数据审计发现并修复固定颜色偏移捷径、开发集接触测试延迟条件及无证据请求计分问题，独立原始报告账本未发现标签错配。详见`V05_DATA_AUDIT.md`。

资源与梯度原始文件：`results/v05/preflight_data_v2_cpu/`，包含数据、诊断程序和核心源码哈希。当前完整组合的分离端口通信梯度L2范数在32/128/512节点分别约0.20661/0.08966/0.21398，仅代表单初始化探针。
