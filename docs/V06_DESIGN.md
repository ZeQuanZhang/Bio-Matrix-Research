## 核心计算结构

节点具有固定容量的多维内部状态矩阵，以及受内部状态调节的外部输入与输出映射。外部输入先被过滤和映射，再影响内部状态；节点根据当前状态变换消息，并通过局部连接与其他节点协作。长期训练塑造计算规则，运行状态和局部可塑性承接当前经历。

输入驱动、节点内动态、节点间传播和输出读取组成主干。概率判断参与经验使用与更新；幅度、频率和相位参与动态保持与局部协作。相关机制可以共享特征计算，但可信度、活动强度和适用性保留各自的含义。

网络组织为由多层同心球壳离散化的实心球体。几何位置用于组织局部连接和径向关系；节点承载的高维内容另行表示。采用预先计算的候选邻接，允许局部和跨壳连接。

向外传播由脉冲强度、内容匹配和节点状态控制跃迁。向内回落允许，不附加与向外跃迁相同的门槛。回落可以改变内层状态，后续向外发送仍遵守跃迁条件。运行中的回落与训练梯度传播分别定义。

## 信号与状态容量

单条消息保持固定形状与固定大小的元信息。节点更新消息内容，沿途不追加节点列表、变换历史、导数或原始输入。分支汇合使用固定宽度的聚合或混合。

节点状态、局部影响痕迹、响应估计、时间尺度数量与证据统计均有明确容量上限。网络内部反复活动继续使用已有证据，不增加独立观测次数。

模型不承担逐项还原任意长历史的目标。计算过程的调试记录、训练日志和可恢复检查点属于工程记录，不能暗中成为模型运行时可查询的历史库。

## 前四点的设计决定

| 议题 | v0.6 采用的方向 | 验证重点 |
|---|---|---|
| 经验表示与调用 | 用多维特征、内部矩阵及有限模态表达经验，由当前输入与历史状态影响调用 | 内容可读性、模式区分和共享节点的串扰 |
| 证据与不确定性 | 根据可用观测、情境和来源信息判断相关性与可靠性；采用固定容量的近似统计 | 校准、来源依赖、规则变化和无关历史隔离 |
| 贡献分配 | 局部资格迹结合有方向的结果反馈，借鉴 Filtered-x LMS 的传播响应补偿 | 延迟反馈方向、闭环影响和未激活候选连接的学习 |
| 情境变化与恢复 | 输入改变路径上的激发强弱；旧情境返回时重新激发仍可响应的结构 | A 到 B 再到 A 的恢复，以及持续学习对旧路径的覆盖 |

第三点的资格迹与响应估计按局部连接或经验模态设置固定预算。输出误差回到内部特征空间后参与局部学习，避免逐节点复制整个输出词表的响应模型。完整时间反向传播可以提供比较参考，局部规则的精度单独评估。

硬跃迁门槛的训练方法仍需确定。平滑代理导数是候选方案；完全未被访问的路径需要明确的探索或诊断安排。

第四点不预设一个独立的经验生命周期控制器。节点使用当前内部状态，无需恢复过去的矩阵版本；旧功能的恢复依赖相关响应结构仍然保留。快状态、慢参数和局部更新承担保持与修订。全网多情境副本与单份持续状态的差异，属于需要配对验证的表示选择。

## 稳定性与数值实现

稳定性检查同时覆盖消息幅度、节点状态、路径切换、可塑性更新与训练敏感度。允许有界振荡、较慢衰减和非零长期结构，避免统一的强收缩过早抹去历史影响。

振荡部分优先采用增益已知的结构化旋转与显式阻尼。矩阵调制、输入注入、旧活动保留、分支汇合和反馈都计入整体增益。单条边衰减、条件旋转保幅或状态取值有界，不能单独作为全模型稳定性的验收依据。

优先通过参数化与轻量归一化控制增益和状态范围。具体全网充分条件在更新式确定后推导。全网雅可比、特征值分析和李雅普诺夫验证用于离线分析或抽样诊断，不进入常规推理的逐步计算。

相位、门控与映射依赖动态状态时，训练需检查这些控制路径的导数。硬门槛附近采用切换系统的视角检查扰动与抖动。梯度裁剪作为训练措施保留，其效果与前向动态稳定性分别检查。

## GPU 计算预算

优先使用批量矩阵乘法、矩阵与向量乘法、外积、逐元素运算和规则邻接上的聚合。节点维与批量维组织成可批处理张量，减少逐节点 Python 调度、临时状态重建和重复归约。

| 项目 | 预算原则 |
|---|---|
| 节点数 | 保留网络规模研究，规划包含 32、128、512 节点；不以小规模单节点获胜作为扩大规模的前提 |
| 节点内部维度 | 固定并计入状态、运算和训练激活预算 |
| 候选连接 | 固定度数或受控块连接，避免每次输入构造全节点两两连接 |
| 多频与时间尺度 | 数量固定，保留有限的单模式与交叉项 |
| 内部迭代 | 设置明确上限，分别报告有效传播覆盖与实际成本 |
| 概率更新 | 新证据到来时执行测量更新，内部循环不重复收缩不确定性 |
| 资格迹与响应估计 | 固定粒度和阶数，避免完整路径模型和全参数敏感度张量 |
| 动态协作群 | 先由活动通路形成；掩码与真实跳过计算的收益分别测量 |
| 优化器 | 沿用普通一阶优化，暂不叠加新优化器研究 |

若每条消息为 d 乘 d 矩阵，内部迭代为 J，序列长度为 T，固定候选度数为 k，则传播主干的目标量级为 O(B T J N k d²)。该目标要求矩阵更新、时间带与傅里叶算子满足相应预算，其他映射、慢参数重建和读出另行计账。

一般的双侧稠密矩阵更新可能带来 d³ 成本。由 R 个稠密基底重建慢矩阵需要 R d² 成本；R 随 d 增长时必须显式报告。完整协方差若针对 d² 维状态建立，存储还可能达到 d⁴，不能隐入概率模块的名称中。

固定状态推理的存储与历史长度解耦。完整反向传播仍需要保存或重算序列与内部迭代的活动；资格迹不会自动消除这部分显存。训练窗口、重计算、局部学习精度与吞吐分别记录。

## 从 v0.5 继承与调整

优先复用条件旋转、局部多频耦合、多时间带、有界局部更新、恢复记录及实验状态登记等已有机制。新球体拓扑、向外门槛、回落语义和新的贡献分配规则需要按本版本单独落实。

先处理可以保持数学含义的代数改写和重复计算，再验证会改变表示能力的调整。

| 类型 | 已识别的处理事项 |
|---|---|
| 代数改写 | 标量测量的 Joseph 更新改写为外积组合；对外积消息先执行矩阵与向量乘法 |
| 结果复用 | 基底归一化、同一状态版本的慢矩阵、相同输入的门控输出和重置模板 |
| 表示选择 | 全网情境副本与路径竞争方案；慢矩阵参数化；不确定性与影响痕迹的粒度 |
| 时间组织 | 区分新证据更新、内部传播、局部可塑性和全局优化的触发时机 |

CPU float64 对 d 为 4、8、32 的代数核对中，两项改写的最大绝对差均低于 4.3e-14。协方差重排仍需验证目标精度下的正定性、梯度和数值误差。当前没有据此给出 GPU 提速倍数。

完整路径记录、依靠最终余量还原全部历史、全模态傅里叶组合、逐路径响应模型、额外群体聚类与动态专家创建，不纳入本版本的主干。JEPA 和逐节点嵌入完整大模型保持排除。

## 实现与实验验收

第一步核对消息与状态形状、增益预算、拓扑方向和更新依赖，完成必要的代数与梯度一致性检查。随后在目标 GPU 上分别剖析推理、前向加反向、激活重计算和局部学习，记录吞吐、显存及计算覆盖。

相关历史利用、无关历史隔离、情境切换、旧路径再激活、同情境规则变化和延迟反馈分别检验。扩大节点数量时，同时记录状态容量、图度数、内部迭代与实际成本。

主能力证据使用业内常用的公开数据，中文或英文均可；首轮已选择 WikiText-2 官方三份切分与仅 train 拟合的 byte-BPE。合成流用于机制诊断和回归。模型与对照规模控制在 1B 以内，披露参数、状态、数据、计算与运行时间的匹配方式。

v0.6 使用独立协议与结果目录，不将旧版本结果改标为新版本。正式条件分别登记未执行、运行中、已完成、失败和中止状态。用户已授权实现、下载与工程检查，正式长训练保留可直接启动的 PyCharm 入口。
