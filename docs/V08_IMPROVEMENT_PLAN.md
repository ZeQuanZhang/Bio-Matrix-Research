# Bio-Matrix v0.8 候选改进与实验方案

> 归档说明：本文保留写作时点的设计或状态。项目已停止v0.9后续训练；最新执行状态见[实验索引](RESULTS_INDEX.md)。公开副本不含权重与语料。

日期：2026-10-24（北京时间）。状态：研究方案；已有独立 C＋F1＋R1 工程候选及本机 MPS 实测，正式研究训练与其余支线尚未执行。

实现进展：见 `v08/README.md`。工程测试保存于 `results/v08/mps_20261024_arrival_gate/REPORT.md`：26项检查通过、36个工程条件完成；首轮3个失败及根因诊断另保留。当前仅完成短更新的计算正确性和吞吐检查，尚未验证长期质量、历史收益、规模收益及逐token生成接口，不计为下述S/E/H/M/G正式实验已完成。

本方案依据取回的43组完整v0.7结果、10个条件全部24,000步训练诊断、保存的逐token预测及既有数学/拓扑分析。N512 independent/full seed37只有暂停检查点，仍标为未完成。v0.7冻结代码、检查点、数据、原始报告与备份均保留。

**目标与版本边界**

目标是让完整Bio机制稳定学习、保留可辨识的当前内容、按相关性调用历史，并降低实际计算成本。首先改进训练规则和公共信息通路，再比较新动力学。

| 版本标记 | 改什么 | 是否与v0.7数学函数相同 |
|---|---|---|
| v0.7-frozen | 原始基准与历史结果 | 原版本 |
| v0.8-S | 稳定训练规则、按证据修复内容路径 | 部分变体只改变梯度；内容修复会改变前向 |
| v0.8-E | 在选定S模型上做代数复用与工程提速 | 目标是实数算术下相同，另验浮点轨迹 |
| v0.8-H | 重接径向图、分层向外、反馈延迟到后续token | 新动力学 |
| v0.8-M（独立通信支线） | 少量局部边＋固定秩公共模式、可分相位矩 | 新通信核，与H/C分别比较 |
| v0.8-C（研究支线） | 旋转坐标系结构化快递推、块边界慢更新 | 新动力学，先有顺序参考再实现chunk |
| v0.8-G（可选支线） | 固定节点组的真实选择性执行 | 新访问/状态演化规则 |

S→E是首轮交付；H独立对照；C/G不能与S首次训练一起混入。所有新条件起始状态均为not_executed，结果注册区分planned/not_executed、running、completed、failed、aborted；暂停记录单列检查点，不冒充完成。

**一、完整保留的机制**

保留节点完整d×d快/慢内容矩阵、m/P概率状态、节点形状参数、动态输入/输出映射、多个时间带、有限trace/support/innovation、相位与Fourier耦合、脉冲跃迁、定向局部修订、有限信用元信息、跨会话内持续状态和独立/相关情景判断的训练目标。

默认S/E继续d=8、width=64、3时间带、3相位模态、2 trace带、H=8信用缓存、4096-token会话、FP32。保留m/P观测坐标、Joseph更新、query子空间容量投影与正交内容保护。不得因为梯度大就清空整个slow，不通过无限路径信息、情境ID、外部检索器或完整情景副本补能力。JEPA、新优化器、二阶反应模块、动态专家群不进入本轮。

保留完整机制不要求每一项都在每token关键路径重复计算。改变更新频率的版本必须明确写出训练和推理共同采用的新时序。

传播、读取和写入的控制分开验收：传播门判断信号能否沿路径到达；读取门判断当前query是否值得使用已有经验；写入门判断新证据如何修订当前方向。沿用已有控制器槽位，优先让读取置信度检查query方向的qᵀPq及创新，而非只看平均不确定性和能量。此特征修订单独配对，不与首批F/R因素同时加入。高能量不自动代表历史相关，高创新也不应清除整份旧经验；局部更新继续限定在当前query方向，并保留正交内容。模型不获得隐藏的相关/独立标签，三个门也不宣称能够从单次输入无误识别真实独立性。

**二、先进行不更新参数的归因**

第一批选6个代表条件：full N32 seed11/37、full N128 seed11/37、message N512 seed23、Transformer N32 seed37。对best和last分别做T=8/32/128的固定开发流反向回放，共36次；不调用optimizer.step。冷/暖状态差异只在定位到异常的位置追加。

1. 参数分组：内容编码/读出；状态依赖控制/通信；node_shape；时间/速率/耦合标量。tied embedding只计一次。
2. 每组记录裁剪前梯度L2、每参数RMS、最大值、占总梯度平方比例。训练探针额外记录实际Δθ，不拿裁剪系数代替Adam步长。
3. 对x、m、P、slow、相位、边权、key归一化输入和pooled hidden抽样测VJP/JVP增益。诊断默认每100次更新一次，异常时短时加密；不为每token落盘整网张量。
4. 比较embedding、输入映射、各壳状态、pooled读出的当前token可辨识率、有效秩、节点相似度。线性probe只在train/dev拟合和选正则，报告参数量与样本数，禁止用正式test选择结构。
5. 把真实token、平衡词频控制、输入置换、随机标签probe分开，防止探针只学到词频。

阶段产物是梯度放大的首个位置、时间跨度及内容区分度下降的位置。现有证据不支持预先认定Fourier、容量投影或任何单个模块就是责任源。

**三、首要训练配对：只改变局部写入的反向规则**

当前缓存的query、读权重、gain、head输入等已detach；但local_direction仍依赖当前embedding、read_projection及head_vjp里的参数，未来loss可通过写入方向继续反传进这些参数。

令D_t为现有局部方向，g_t为缓存增益，η为可训练基础速率：

- F0：ΔS=ηg_tD_t，保留当前梯度。
- F1：ΔS=ηg_t stop_gradient(D_t)，仅把方向作为一阶局部修订。

F1保留相同前向数值、写入限幅、容量投影、可训练raw_slow_rate、旧slow到新slow的梯度路径，以及slow对读出、控制和未来活动的作用。禁止把整个slow或整个模型状态detach。F1是明确的一阶近似训练规则，不能称为原函数完整梯度。

验收：同权重/同输入/同状态时F0/F1前向状态与logits一致；方向路径的梯度按定义切断，学习速率参数和旧slow路径仍有相应梯度。F1不能用完整前向函数的有限差分来冒充其代理梯度正确；应检验所规定的梯度规则及残余路径。

先比较F0/F1，不同时更换优化器、精度、拓扑和所有归一化。若F1无改善，回到归因而不是继续堆stop-gradient。

**四、恢复内容通路，按probe结果选择改法**

首选候选R1是网络内部内容残差：从embedding生成固定宽度当前内容，经入口、节点映射和传播到外壳；经验分支对该内容作有界修正。输出仍读取网络，禁止把原始embedding直接加到最终logits并把收益算作Bio机制贡献。

一种可实现形式是：u_i=Σ_j a_ij h_j，h_i=u_i+γ_i Φ_i(u_i,完整节点状态)。当前内容的基础传输与复杂记忆修订分开；γ只作用于相应交互残差，不把全部长期状态统一压小。R0关闭该新内容分支，保留原路径。共享参数使用相同初始权重，新分支使用独立固定随机源。

默认d8/w64候选将当前内容保持为64维（可reshape成8×8），入口W_c采用保范初始化；动态节点映射作为恒等基础加有界修正，不要求16维key/value承担全部当前内容。可用γ=0.3·sigmoid(r)、初值0.1作起点。新增投影参数和激活如实计入预算，并重配参数接近的基线；不声称该残差本身保证优化稳定。

S阶段仍使用原候选图，不能仅用四个内部tick保证任意归一化内容都已抵达表层；需实际测到达和区分度。H阶段的分层父边保证当前内容逐层到达，γ=0时可构造出与stateless相同的基础内容函数。R1的收益必须与完整记忆贡献同时验收，防止记忆分支被忽略。

如果probe指向其他位置，优先用更直接的对照替代R1，不叠加：

- 入口受限：固定Nd²=32768，比较(N,d)=(32,32)/(128,16)/(512,8)。单列总参数、trace、信用缓存和实际FLOPs，不能宣称总状态完全相等。
- pooled汇聚丢失内容：比较1/2个读取头，必要时再4头；首个候选共享每节点query，仅分读取权重与输出投影，局部VJP使用每个头真实贡献之和。若进一步采用不同query，需重推query联合子空间的容量投影与缓存，不直接套用旧单头算法。
- 原状态幅度很小、读出放大：按实测尺度修输入/读取增益与归一化，先测节点区分度再考虑加宽。

**五、数值和优化设置的修订规则**

以下是由诊断触发的少量候选，不执行全参数笛卡尔积：

| 项目 | 初始处理 | 仅在何种证据下修改 |
|---|---|---|
| 近零normalize/cosine | 记录原始范数、eps附近比例和局部增益 | 异常与该位置同步时，测试平滑u/sqrt(||u||²+eps²)，eps按train单位校准；1e-4/1e-3/1e-2为候选 |
| STE门梯度 | 保留硬门前向 | 确认该路径主导时比较temperature .01/.02/.05；软门训练阶段的变化也记录 |
| 交互残差增益 | 非线性支路小增益初始化 | 可试.03/.1/.3，仅约束被定位的支路；不宣称整网Jacobian已被证明有界 |
| 局部学习速率 | 保留.02·sigmoid(-2)≈.002384及participation校正 | 慢更新被定位为失稳源时比较.25/.5/1倍；不按N再盲目放大 |
| 时间信用 | 保留全程BPTT128作为基准 | 对照32→64→128课程；前向会话持续、不清内容状态 |
| 优化器 | AdamW、FP32、当前beta/eps | 先修参数组和梯度路径，不换新优化器遮盖问题 |

候选学习率：内容编码/读出3e-4，控制/通信/形状1e-4，时间与速率标量3e-5；每类只在开发集做相邻档校准，所有结构获得可比搜索预算。bias、LayerNorm和raw时间/学习速率标量不做weight decay；大矩阵默认0.01。先保留全局clip1；只有确认某组支配总梯度，才单独比较组内clip，不同时改所有阈值。

BPTT课程若采用，按预先冻结的有效token里程碑进行：0–0.25M为32、0.25–0.75M为64、之后128，最终与全程128比较；batch2、每流128个可见输入、每更新合计256个可见输入不变，短BPTT仅增加一次更新内部的backward/detach次数。optimizer边界信用缓存失效仍执行一次。课程不改变历史状态生命周期，也不补足无限时距信用。

学习率日程从开始就按最终计划token预算定义，中途pilot停止/续跑不重启warmup或cosine。候选warmup为最终预算前2%，开发阶段可比较1%/5%，不能因延长训练临时拉伸已执行日程。

具体地，pilot统一按最大观察预算3M定义日程，0.25M和1M只是停止检查点；正式训练另从零按锁定的12M/24M预算定义。不同日程的旧运行不得当成可无缝复用的同一对照。

稳定性同时看非有限值、模块增益、实际参数更新、内容可辨识和验证曲线。百万级梯度中位数应显著下降，但不能靠改变loss归一化或仅以梯度绝对值验收。正常对照也可能经常触发clip1。

**六、S阶段的实验矩阵与预算**

若归因支持F1和内部内容残差，运行F0/F1×R0/R1四组，全部保留完整Bio：

| 档位 | 条件 | 用途/有效目标token预算 |
|---|---|---|
| B1 | 4变体×3规模×seed11=12条 | 每条0.25M；只检查数值、梯度、内容起步，不判断长期机制成败 |
| B2 | 选2个共同候选×3规模×seed11/23 | 延至每条1M；最多18条独特trajectory，Bio累计13.5M |
| 对照 | 实际独特的TF配置＋stateless，各seed11/23 | 通常最多6条×1M；不按N标签重复同一配置 |
| 晚期观察 | 保留候选按预注册条件延至3M | 旧message成功分支约3M后才稳定，不能仅因0.25M或1M不胜出就淘汰 |

若probe先指向输入宽度/读取而非残差，R因素由该单项候选替换，试验数量不自动扩成所有因素组合。方案选择根据三个规模的共同证据，不因32节点没有胜出而取消128/512。B1/B2是诊断筛选；未达到数值失败或预注册退化条件的后起学习分支须保留观察预算。

B1/B2的Bio总量上限13.5M，通常对照另加6M，基础合计19.5M有效目标。晚期观察单独预留：若12条入选trajectory均从1M延至3M，最多再加24M；不得将这笔延长成本隐藏在pilot总量里。

若晚期观察要比较同预算能力，对照也延至3M，通常六条对照再加最多12M；若只观察梯度和后起分支，则明确不作3M Bio对1M基线的公平胜负结论。全部可选晚期延长都执行时，S段总上限为55.5M有效目标，不默认一次跑满。

**七、E阶段：保留函数的数学与工程优化**

| 项目 | 实现 | 保留/验收 |
|---|---|---|
| fresh包 | D_i=a_i[v,k,1]，传播幅度a代替17维包 | 保留mass floor、近零key和零梯度语义；完整8×8内容消息不压 |
| Fourier投影 | W[f_i;f_j]=Af_i+Bf_j，按节点算再组合 | 后续非线性仍逐边执行，不任意把sigmoid拆开 |
| 静态控制 | 每token缓存4轮内不变特征的线性投影 | 保留动态特征与原非线性控制 |
| Joseph | 合并三项外积为一项系数外积 | 完整P、PSD/对称化、variance floor和实际观测保持 |
| 慢写 | 向量/秩一中间量完成限幅和query投影 | 最终S完整，近容量边界检查浮点相消 |
| 输出/诊断 | 批量化可合并计算，减少host同步 | 当前逐token反馈的真实依赖不能被偷偷延迟 |

控制/Fourier投影子部分原估算N512/J4为8.65M→4.87M MAC/token；不是整网倍速承诺。

fresh包标量化有前提：传播中各节点共享同一原始包、各通道使用同一标量边权、节点过滤不写回drive。R1若引入不同节点内容或多方向包，仅在仍满足该前提的fresh子通道应用；新内容通道保留自身完整表示。不得将旧rank-one证明直接套到任意新消息上。17维仅是d=8旧fresh包的数字。

Fourier仿射拆分的bias只加一次。单query慢写的秩一优化限于实际更新仍为Aqᵀ：共享query的多头先合并方向可保持该结构；不同query之和则需另证，不能继续把总更新当秩一。

测试层级：FP64单算子前向/梯度；FP32含近零和硬门边界；固定权重长会话；相同起点短程优化；checkpoint精确恢复。初始模块容差可用FP64 atol1e-10/rtol1e-8、FP32 atol1e-5/rtol1e-4；梯度用相对误差与方向同时看，接近零单列。硬门远离阈值的判定应一致，阈值邻域差异和后续轨迹需单独追踪，不能用平均误差掩盖分支变化。正式容差在看测试结果前由这些开发回归冻结。

先单任务测，再测队列总吞吐。编译/预热单列；稳定后每测窗30–60秒、至少3次，固定batch、线程、精度、数据、参数状态和日志频率。记录有效目标/秒、更新延迟、GPU/CPU时间、内核数量、显存、主存与采样区间。实测无收益的重排不进入默认路径。

**八、H阶段：重新设计向外传播与返回**

沿用中心＋3个球壳。新建固定父边A_l，每个非中心节点至少有一个父节点，并保证每个内部节点能通向一个输出端口；平衡覆盖后补几何近邻。默认每目标最多4个父节点，mask和索引预生成。

返回使用同一父边的转置A_lᵀ做分组归约，保证所有有效路径可返回。总边消息至多2kN，仍为线性；中心/部分父节点反馈扇入可超过8，明确记录，不能同时宣称所有节点双向邻居都≤8。N512原层容量[1,57,154,300]下，中心不可能只用8个双向邻居直接连接第一壳57节点。

返回不能直接无界求和。对不含脉冲/置信幅度的基础路由权重A，使用B=diag(Aᵀ1)^−1 Aᵀ（零列输出0）的有界归约；实际边门和置信幅度乘在消息分子，归一分母不随共同置信幅度缩放，避免把低置信度重新归一成满强度。反馈增益有固定界；中心接收很多子节点时幅值不随N线性爆涨。验收零输入、零门、共同置信缩放及不同扇入下的幅度。

默认每token先逐层向外，输出本次预测，再外到内归约一次反馈；该反馈仅改变下一token所用状态。反向梯度照常，功能反馈与autograd反传分开。不得在同一token返回后重新启动无限向外循环。节点信息和返回摘要均固定宽度。

主对照是稳定E原图、H0新径向图无功能返回、H1同一新径向图有延迟返回。H0/H1参数、输入、图、端口和固定反馈槽一致，H0槽置零；分别报告返回的计算成本。原图和新图不能假称相同图，比较时报告边数、总状态和实际工作量。

先3结构×3规模×seed11=9条，1M开发token；再对新径向H0/H1补seed23=6条，最多15条独特trajectory。原图参考已在相同数据/预算下完成时可复用，不重复计独立证据。后起候选统一按规则延至3M。所有规模都完成配对，不以小规模优胜作前提。

若原图seed23没有完全相同数据、token预算与学习率日程的可复用运行，补三规模seed23，合计18条，形成三结构两种子的完整对照。

图验收包括：全节点从入口可达、全节点通向读口、启用返回时全节点可回入口、断面隔离、输入语义与历史载波能量均为零时向外门严格关闭、无同token闭环。仅新输入为零但历史载波非零时允许持续活动。稀疏图最短路可达不等于门控后必然可达，动态到达也须测量。

**九、C支线：先定义可组合快递推，再实现chunk**

H仍逐token，不能自动解决时间轴串行。C支线保留完整快矩阵，但约束块内系数来自当前因果输入/前层输出与块起点的慢上下文c_b：

(k_t,v_t,q_t,α_t,β_t,L_t,R_t)=f(u_t,c_b)。

它们不得再读取本块尚未生成的快状态或未来输出。空间通信在同token按层向外，复杂返回在块边界发生，避免跨节点任意循环转移相乘变稠密。

物理坐标：Fhat_t=L_t F_(t-1) R_tᵀ；F_t=α_t Fhat_t+β_t(v_t−α_t Fhat_t k_t)k_tᵀ。

旋转坐标：F_t=Q^L_t H_t (Q^R_t)ᵀ；Q^L_t=L_t Q^L_(t-1)，Q^R_t=R_t Q^R_(t-1)，ktilde_t=(Q^R_t)ᵀk_t，vtilde_t=(Q^L_t)ᵀv_t；H_t=α_t H_(t-1)(I−β_t ktilde_t ktilde_tᵀ)+β_t vtilde_t ktilde_tᵀ。Q^R与概率协方差P区分命名。

固定二维分块、固定配对轴的正交旋转可累计角度；动态改变旋转平面时不能直接对角度求前缀和。多个时间带各保留一个完整矩阵。单位key与α/β∈[0,1]可约束条件快态转移的范数；不构成整网全局稳定证明。不能把当前每步bounded、状态依赖频率/边权和输出反馈原样塞进scan。

条件Jacobian非扩张也不自动给出统一状态幅值界。C必须另行保留有界value，并选择明确的界：严格α_max<1的阻尼，或块边界的快矩阵容量投影。候选默认沿用半径4的快矩阵投影、移到块边界，在顺序和chunk参考中执行同一投影；块内不逐步投影。其块内幅值与边界雅可比另验收，不能把旧每tick半径4直接宣称为新模型每一步的界。慢矩阵的query方向容量投影独立保留。

慢S、m/P、支持度和复杂概率控制在块起点冻结供读取，块末对已经观测到的反馈按时间顺序更新。Joseph、query子空间投影可以先保留边界顺序实现，剩余串行工作照实计时；不能把一个块里的相关观测冒充独立证据或把多次局部投影偷换为一次全局投影。

边界事件固定为：旧块完成→按时间顺序重放截至旧块最后可见输入的已到达反馈和fresh观测（每位置先消费前次反馈，再对当次观测做一次先验/Joseph与trace/support更新）→旧块末预测留pending。返回摘要从旧块前向快照生成，不能按重放后的慢状态重新生成旧预测。下一块首输入先处理合法旧pending，再冻结新上下文；该首输入自身的key/value由新上下文生成，归入新块观测，不提前更新m/P后再生成自己的观测。

块长默认候选16，比较1/16/32。C=1是同一新模型的最短反馈延迟参考，不等于旧v0.7。块内第t次预测必须等实际x_(t+1)到达才获得反馈：块尾最后预测先标pending，下一块首token到达后，在参数版本匹配时先消费旧pending，再冻结新上下文，之后才向环缓存写新预测。训练target不得提前更新生成该target预测所用状态。训练和逐token推理采取相同因果时序。

将有限信用/块元信息槽统一设为32，供上述时序对照；记录query、读权重、head输入、expected embedding、gain、read_scale、时间编号、head参数版本和有效位/pending，不保存32份完整网络状态。按实际分配容量计总状态预算，不沿用旧H8字节数。

C32的32个槽足以容纳一个块；必须先消费或显式失效上一块pending，禁止先push导致覆盖最老帧。optimizer.step改变head后沿用v0.7参数版本政策：失效旧head信用，包括未消费pending，记录跳过次数；不以新head解释旧缓存。正常无参数变化的推理每帧恰好消费一次。会话reset、padding和显式失效的处理均有对应测试。

先写顺序参考，再在相同C和相同慢更新顺序下实现chunk；检验输出、最终状态、梯度、padding、重置与流式分块一致性。未来token扰动不得改变过去预测。分块输出头/控制投影可整块GEMM，具体delta分块三角计算的额外工作也须计入。论文依据是Gated DeltaNet的结构化更新与硬件友好分块算法；新Bio的收益需自己测量。

**十、G支线：实际跳过节点组**

基础模型稳定后再加。固定每组16或32节点，每块选定固定数目组，预分配执行槽；包含必要祖先及输出路径。选择只依赖块开始时已有信息，禁止用整块未来输入平均值选路。祖先闭包后的真实组数计预算，不能只报最初Top-R数目。

未激活组的内容不清空。只有模型已规定为固定指数衰减/固定轴旋转时，才可用经过时间解析补算；m/P按实际观测事件更新，跳过不等于收到零证据。若频率/控制仍依赖未计算状态，就不能称惰性补算等价。

G须单独规定未激活组的自主演化律，不能自动继承C中依赖当前输入的活跃系数；两者的规则差异计入访问模型和训练协议。

先覆盖全部组，再逐步试100%/75%/50%实际组预算，保留固定探索/轮转名额，防止永久失活。检查快切换、罕见线索和A返回；路由和摘要成本计入总吞吐。没有端到端收益时不启用。

3. 外部上下文任务使用官方LAMBADA，dev用于确定评分接口，test封存。报告最后词NLL及整词精确匹配（可能包含多个BPE）；小模型若准确率接近地板，仍报告NLL和覆盖范围，不用更换目标来掩盖结果。

MQAR诊断不能替代自然文本与LAMBADA的能力结论。不同文档或没有词元重合，均不能自动当成统计独立真值。

训练采样、可见标记、CE掩码、状态重置规则对各模型一致；日志中的隐藏source信息不进入路由/反馈。训练中的相关/独立/修订情形混合出现，模型自行判断。

锁定一套S/E或H后，正式核心：message/independent/full×3规模×2seed=18条；加实际独特TF配置各2seed与stateless各2seed。通常24条，补第三seed后36条；若TF有3种独特配置则26/39条。额外Gated Delta矩阵递推参考先在128参数配对运行2seed，随后第3seed，成本单列，不混进重复控制数量。

两种子阶段只作中期报告；需要宣布三种子稳定性或采用“至少2/3”验收时，按预注册补齐第三种子，不依据前两种子方向好坏选择性补跑。

正式token候选档为12M或24M有效目标，依据开发pilot的学习曲线、吞吐和成本在正式开始前选定共同档位；默认从12M规划。步数按真实有效目标计数推导，不能直接沿用4000或24000。优化器更新token批量同步记录，边界mask造成的可见token差异照实报告。

按每规模先完成配对、再补种子；不把N32胜出作N128/512前置条件。数值错误、目标/状态协议错误或超出预定资源才中止；不能看到某条件效果差就单独提前停止正式训练。报告best-validation和last，预算扩展只允许预注册、可比的整组延长。

**十四、早间数学方法的完整对应与补充通信支线**

本节对照results/v07/math_analysis_20261024/MATH_OPTIONS.md，避免将“分阶段验证”误解为删除数学路线。此前详细方案已写入E/C两类；少量局部边＋固定秩公共模式及可分相位矩在初稿中漏列，现补为独立M支线，不并入等价优化，也不默认与H/C/G同时叠加。

| 早间方法 | 当前安排 | 验证状态 |
|---|---|---|
| fresh包精确秩一表示 | E；只优化满足共同包前提的通道 | 已有局部FP64检验，待FP32轨迹/GPU |
| Fourier节点投影＋静态控制复用 | E | 拆分有代数依据，待整网验收/计时 |
| Joseph外积合并 | E | 已有局部FP64前向/梯度检验 |
| 慢写入秩一中间表示 | E；最终经验矩阵仍完整 | 已有推导，容量边界仍需验证 |
| 旋转坐标系＋定向delta快记忆 | C | 已有候选两种坐标表示的FP64检验，未训练 |
| 局部边＋固定秩公共模式 | M；与原通信和H分别比较 | 推导候选，未训练/测速 |
| 可分相位耦合的sin/cos矩 | M；满足可分条件才精确 | 代数恒等式，不等于原任意pairwise核 |
| 蝶形/Givens规整混合 | 保留备选 | N512有9级依赖，不预设比J4快 |
| 小秩线性隐式反馈 | 保留备选 | 先验证小系统可逆性/条件数，不直接替换非线性四轮 |
| ParaRNN/DEER类非线性时间并行 | 远期备选 | 需适合的Jacobian结构与收敛验证 |
| FFT/球谐/共享谱模态 | 有结构条件的备选 | 不对任意动态球图直接套FFT |

M的内容矩阵仍为完整H∈R^(N×D)，d8时D=64。通信结构取W=A_local+ΦΨᵀ，计算WH=A_local H+Φ(ΨᵀH)，只让跨节点通信可分，不能把每个节点积累的历史矩阵压成永久低秩状态。

非负Φ/Ψ时，局部边和公共模式共同归一：m=[A_local H+Φ(ΨᵀH)]/[A_local 1+Φ(Ψᵀ1)]，按行相除、零分母输出0。内容H可以有正负。分别归一后再相加属于另一个通信核，不能声称相同。

公共摘要固定为r×D、每次覆盖。按允许的球壳、方向和断面分区，cut之后不得经公共模式跨界。若比较严格“同token只向外”模型，公共模式只连接相邻层或在块边界返回；不能悄悄加回同层实时广播。当前模型本来固定K8、复杂度已是O(N)；新通信约N(k+2r)D，另计特征生成/控制/访存。k2/r2约6N，k2/r4约10N，后者可能更贵。M首先比较原核与k2/r2，再按容量/质量决定是否试r4，不默认增加一批全组合训练。

相位矩利用恒等式Σ_j b_j sin(θ_j−θ_i)=cosθ_i·Σ_j b_j sinθ_j−sinθ_i·Σ_j b_j cosθ_j。每个保留频率只需两个公共矩；接收/发送权重须可分或为有限项之和，且相位项线性进入。现有pairwise相似度sigmoid、硬门和整体Fourier sigmoid破坏一般可分性；改成矩核是新模型，不属于原函数的免费重排。

空间低秩不自动带来时间可scan，连续状态转移可能涨秩或变稠密。与C结合时，公共通信应来自已完成的前层或块边界摘要，重新证明因果/可组合性。
