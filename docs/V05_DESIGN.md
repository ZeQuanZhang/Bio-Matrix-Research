# Bio-Matrix v0.5：传播、巩固与可修正的长期经验

> 归档说明：本文保留写作时点的设计或状态。项目已停止v0.9后续训练；最新执行状态见[实验索引](RESULTS_INDEX.md)。公开副本不含权重与语料。

本轮将完整组合直接纳入 32/128/512 节点配对，不以单个小单元超过基线为扩大规模的前提。v0.4 的源码、正式训练与结果目录保留。新代码位于 `v05/`，PyCharm 入口为 `run_biomatrix_v05.py`。

## 研究问题与可证伪结果

1. 分离读写端口后，信号是否到达输出，任务误差是否到达通信参数？正交载体的能量保持不自动保证目标信息可读。
2. 相关历史能否改善判断，无关历史是否污染独立新观测？情境切换、同情境规则改变与旧情境返回分别测量。
3. 经过独立后续报告验证的经验，能否改变节点的慢权重，并在清除短期矩阵后继续发挥作用？
4. 延迟反馈能否通过资格迹产生长期变化？完整反传与截断反传另设对照。
5. 长期经验越充分，纠错是否越来越慢？验证驱动、使用频率驱动和始终采用旧经验分别比较。
6. 增加节点是否产生跨种子收益，固定总状态容量和节点轮次预算后是否保留？

失败证据包括：分离端口信号/梯度接近零；清除慢权重不影响长期探针；频率对照与完整机制同样容易被重复错误影响；规则变化后持续无法纠正；规模收益只来自额外容量或计算。

## 三种学习与时间尺度

- 共享长期规则 Θ：普通 AdamW 训练的映射、读写门控、基底、振荡控制和读出。
- 局部后天可塑权重 a：每条生命周期、每情境、每节点独立的慢系数。它们组成有效关联/响应映射，并参与外部输入映射。在线更新不调用优化器、不读取评分标签。
- 短期运行状态：M/P、多个反应矩阵 X、资格迹、创新滤波、相位/振幅/频率。

a 是功能意义上的可塑突触参数，以函数式 tensor 保存，避免同一个 batch 中四条反事实轨迹修改同一份全局 `nn.Parameter`。它计入状态/存储预算。重启清除短期状态后保留 a、保护度、情境锚点、锚点使用量和有界来源编号缓存。普通流边界从独立生命周期开始；在同一生命周期分块调用时显式传递 state，慢权重可以持续保存。

默认 D=8、情境槽 C=3、反应时间带 L=3、振荡模式 K=4、资格迹时间带 E=2；每节点 a 有 R=4D=32 个系数。所有对照分配同样状态空间；关闭机制的组会保留相应预留状态，报告中不把预留量说成活跃计算量。

## 可观察信号与数据

使用中文可读的结构化设备流：地址、四维带噪读数、来源声明的标准差、报告编号、带噪情境线索，以及真实的查询请求。键固定 one-hot，值处于固定公共坐标。隐藏世界、真实答案、任务阶段、颜色反事实编号、声明是否真实和“反馈”生成标签不进入模型。

正确答案只用于训练损失和评分。查询之后到达的新报告是运行时可用证据；模型没有获得未来报告。可信报告的噪声按声明生成；repetition包含自信但未经验证的声明，标准差不保证校准，本轮没有声称学出了未知来源可靠性。相同编号跳过 M/P 与验证驱动巩固；跨编号相关性尚未建模。

每条原始流构造四个颜色反事实，问题、地址、线索、顺序、来源质量和编号相同，目标逐查询严格平衡四类。不可信声明本身在四个反事实中保持相同，可信历史与后续报告随真值变化；不能从声明减去固定颜色偏移反推答案。缺少独立证据的早期请求仍触发模型活动，但不计入主损失。

练习次数、报告顺序和干扰长度随机化。dev/test固定独立种子，默认每任务分别8/32个基础轨迹；四个颜色变化属于一个相关组。dev排除long，延迟只使用2/4/8；test独立保留long和16/32延迟。共同任务语法仍是限制，不能据此宣称跨语法泛化。保留生成哈希、中文样例、原始概率和逐查询结果。

| 任务 | 主要检验 |
|---|---|
| history | 延迟读取与相关历史收益 |
| independent | 新情境的当前直接观测能否覆盖无关历史 |
| outlier | 单次低质量冲突是否破坏已有经验 |
| switch | 相同情境线索下规则改变后的行为纠正与慢权重修订 |
| return | A 学习→B 学习→清短期状态→A 返回 |
| consolidation | 反复练习并接受独立报告→清短期状态→无新观测探针 |
| repetition | 独立于真值的同一未经验证声明重复及调用→独立纠正→清短期状态探针；前期不计主评分 |
| delayed | 查询后延迟报告是否经资格迹留下慢权重；测试延迟更长 |
| long | 更长的干扰与跨情境保持，仅进入评估 |

`restart` 是人为施加的短期状态擦除操作，所有组共享，不表示隐藏世界切换。普通情境/规则改变没有 RESET 或真值边界。双设备题使用共享的已知模4概率卷积；本轮不把它解释为学到了算术。

## 连续情境竞争与独立读写

固定数量软情境槽，不使用硬创建阈值、LRU 替换或 Top-K 选择。旧锚点竞争、平滑的新颖度和低使用量分配共同产生连续责任概率；锚点连续更新。有限槽仍可能干扰，任务将测量其后果。

全局情境控制器只看到 cue 及 cue 历史，不读取内容值、局部预测误差或答案，因此不能通过聚合答案相关误差向远处节点广播内容。创新与可信度在节点本地影响写入、旧经验适用性和可塑性。当前证据保留原始残差通道。

## 条件保幅传输、显式阻尼与多时间带

图复用已验证的固定度数生成器。将每条无向边恰好分配到一个不相交匹配组，每个内部子步使用一个匹配组；连续轮次覆盖图边。没有根据相位在离散候选之间做硬选择。

对一对矩阵执行：

    Xi' = cos(angle) Xi − sin(angle) Xj
    Xj' = sin(angle) Xi + cos(angle) Xj

节点内再用实数二维旋转分别作用于矩阵左右维度。这些运算在给定角度时保持载体总 Frobenius 能量。角度由状态、角色和多维相位差的单模式/混合傅里叶项产生；相位由局部耦合反过来改变。没有对任意节点编号做 FFT。

每个时间带采用 r_l=exp(−1/tau_l)，默认 tau 从8到512个外部事件。阻尼平均分配在 J 个内部轮次。当前证据和查询唤起内容在一个外部事件只注入一次，所有时间带的输入增益做 L2 归一化，改变带数不会免费增加注入能量。读出使用归一化时间带投影。

局部活动均方与可训练目标活动共同控制有界的新信号增益，低活动时提高输入敏感度，高活动时降低注入；这不会直接重新缩放已保护的历史载体。

这实现了保幅核心、受控写入与显式衰减的组合。动态角度产生额外的控制器雅可比，完整非线性模型仍可能出现梯度问题。每次检查保存任务梯度与输入敏感度，不从能量曲线推断学习成功。

## 概率记忆与创新

复用 v0.4 已测试的 Joseph 更新，每条新外部报告只更新一次 M/P；内部通信和回放不作为独立观测再次收缩 P。带过程噪声与有界门控的协方差是工程近似。

创新由观测前的 M k 与当前读数比较得到，并按状态方差与来源噪声归一化。局部保持创新、冲突、验证收益和来源质量的滤波状态，用于读写及反应控制。

## 资格迹、验证与慢权重

慢映射为 S_i=Σ_r a_ir B_r，共享基底归一化。查询在相应输入端口记录低维、键相关的资格迹，多个时间常数保留资格。后续新报告先检查观测前 M 的预测，再形成支持度和相对慢映射的误差收益。

经过验证的 M 预测成为局部巩固目标，以近似资格迹调节 a 的局部梯度更新。更新有界且保护度可降低；它与 M/P 的观测更新分开，不把额外巩固当作一次新的贝叶斯测量。没有存储可无限回放的原始历史。

这是一种明确的局部学习假说。资格迹使用压缩的局部敏感度与当前误差结合，不声称等价于完整 BPTT，也不声称是生物大脑的完整算法。报告端口获得直接可验证反馈；中继节点通过反应矩阵承载信息，本轮没有额外给中继节点广播真值教学信号。

旧经验使用量受局部适用性、保护度和短期证据精度共同控制。冲突可以先降低旧经验参与程度，再逐步修订慢权重。来源重复、自己调用次数与外部独立验证分别处理。稀有事件的重要性、任务代价驱动巩固、跨来源相关性是后续开放项。

## 完整组合与消融

| 组 | 改动 |
|---|---|
| full | 所有上述机制 |
| message | 相同记忆/情境/巩固/相位调制，载体改用普通门控消息网络；使用共享逐带因子层匹配有效参数 |
| no_fourier | 去除周期傅里叶调制，辅助状态改为等维非周期更新 |
| single_timescale | 同样带数，时间常数相同 |
| no_traces | 不保留跨事件资格，只保留当前请求的局部资格 |
| no_consolidation | 慢权重不更新、不参与读出 |
| frequency_only | 查询调用也能强化 M 中的内容，跳过独立验证，作为固执对照 |
| always_read | 长期映射始终参与，去除适用性与新证据精度调节 |

message 是机制匹配的普通消息传递对照。它共享显式关联规则，不是标准 Transformer，也不是自然中文 LLM。完整组合中的软交互边形成临时协作关系；本轮没有声称形成了可命名的专家或实现了按路由省算。

## 配对、容量、迭代、拓扑与计算

core 默认 2 条读取路径×3个规模×8组×3种子=144条件。依次完成 seed11/N32 的两路径全部配对，再进入 N128/N512，最后 seed23/37。

补充阶段均可直接运行：capacity 精确匹配全部浮点状态，使用有实际用途的时间带、振荡模式和资格迹数量；iterations 比较 J=4/16/32；topology 使用读写分离的断图；credit 比较完整反传与 BPTT16；compute 固定 N×J=4096 的节点轮次预算。all 合计270条件。

固定总状态没有同时固定每个子系统的容量分配、参数和精确计算量；这些差异保留在逐条件 ledger 中。compute 是节点轮次匹配，实际耗时另测，不声称等时间。读出随 N 有相同的显式 sqrt(N/32) 标度；所有组共享并报告。

## 训练、指标与干预

默认整条生命周期完整反传；事件级激活重计算降低存储。训练损失是可计分查询 NLL 加0.05倍观测前预测误差。主要指标为各任务末次查询的宏平均；dev从step0按宏平均末次查询NLL选择最佳检查点，test不参与选模型。所有计分查询的微平均另行保存。保存初始测试结果，区分预设规则与训练收益。

指标：准确率、NLL、Brier、ECE、各任务末次查询、独立历史交换 TV、慢权重收益、旧情境返回收益、逐组任务梯度、实际时间及状态/可塑权重预算。

纠错速度使用“首次连续两次答对中的第一个查询编号”；无法达到者标为 censored 并单报比例。不会将失败样本静默丢出延迟均值。

同一检查点执行 reset_history、swap_history、reset_fast、clear_slow、no_messages、no_coupling、fixed_external。干预可能产生分布偏移，应结合重训消融与任务路径解释。
