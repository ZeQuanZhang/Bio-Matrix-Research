# v1.0：完整构想与可计算实现对应表

本版把有限矩阵记忆嵌入因果 Transformer，并保留一个分段提交的 BioField 协作场。Transformer保留原有计算主干，BioField在内部记忆分支中工作；原版本、负结果与检查点保持原标识。核心 delta 记忆按 token 写入，BioField 读已提交的段起点状态，在固定段边界提交新状态。Python 调用的切分不定义语义，段时钟由模型状态保存。

默认 `memory_enabled/full_dynamics/phase_enabled/probability_enabled/dynamic_enabled/local_feedback_enabled/coupling_enabled/threshold_enabled` 全开，`active_fraction=1`。相位实际改变查询坐标、边传递、状态载波和软协作群。关闭 phase 同时关闭核心记忆的相位寻址与 BioField 的相位/Fourier/频率/振幅/相位耦合，其余机制保留。

## 因果时序与状态接口

`BioField.read(hidden[B,T,W], query[B,T,H,d], state)`只读已提交状态，不改参数、不提交新观察，输出`[B,T,H,d]`。读取当前表示只影响当前位置；不能利用本次调用里后面的输入形成过去的field读取。

核心 `MatrixMemory.prepare` 提供query/key/value `[B,T,S,H,d]`和band_weights `[B,T,S,H]`。场的`accumulate`按固定token顺序累加这些投影及当前hidden的有限投影，保留`key/value/query/hidden sum + count`；同一实际段按任意Python调用切分得到相同累积。没有把当前Python调用的均值当作一个新事件。

段边界 `commit(summary,state,commit_mask)`：先用已观察的本段latent结果消费旧pending反馈，再从入口注入本段有限摘要、执行J轮图通信与振子耦合；按到达情况做一次m/P更新、fast与trace更新；发出对下一段的latent预测并保存在固定信用槽。新状态只供之后的段读取。每lane可独立提交，未提交lane所有字段保持原值。reset用新状态按lane递归替换；不足一段的统计保存在固定缓冲中，后续输入继续累积。

可选稀疏路由只读取已提交m/slow/support/phase及历史elapsed，不看当前hidden、query或当前段未来输入，因此同段及任意调用切分的选择一致。每lane独立选择，保留一条中心到读口的合法父链和一个轮换探索槽；其余取历史分数Top-K。短命view独立持有参数/缓冲区字典，按node轴切完整矩阵及节点参数；诱导子图不增添原图不存在的边。额外选中节点不保证都有完整新鲜可达路径，动态到达仍须监测。

稀疏inactive的m/P/fast/slow/trace/phase/support/innovation原值冻结。全部节点信用槽按真实段时钟移一次，当前inactive槽清零，历史帧保留原全局节点ID。自动lag1只更新当前选中节点；上段选中而本段未选中的节点不更新slow，该帧在自动模式下过期。稀疏因此定义了不同的访问与信用规则。显式延迟模式仍按全局节点ID、有效位及一次消费处理。

选择、CPU路由标量、临时view、gather/scatter均有实际成本。active_fraction诊断报告实际选中数/N；持久状态仍保存全部节点记忆。是否更快需要同预算实测。

局部反馈预测的对象是下一段的聚合潜在结果。对本段末尾预测，必须等下一段实际输入到达之后才能计算误差。场不读取训练target、隐藏来源标签、评分mask或外部数据库。核心与field的运行态均不在forward内部detach；训练器可在明确TBPTT边界截断，需按协议记录。

## 参数固化事务

`consolidate_proposal(state, allow_multilane=False, minimum_support=2, maximum_innovation=.25, rate=.01, max_update=.01)`只生成有限提议，不写参数。默认单会话；显式允许多lane才聚合，不能把lane数量当独立来源的证明。提议带参数巩固版本，过期提议拒绝。

`apply_consolidation(proposal, optimizer=None)`是显式no-grad事务：有限更新node_shape，清理该参数的Adam等历史矩，实际发生改变时版本递增；`invalidate_credit(state)`清掉旧信用有效位。`consolidate(state, optimizer=None, ...)`合并这两步。该事务单独记录，并由训练器显式调用。由调用者统一管理所有共享会话的版本和历史；不能一边保留未完成反向图，一边应用参数提议。

清空运行态后，新m从修改后的node_shape初始化，所以该机制确实跨短态reset保留变化。后续相反、同样通过门槛的提议可以修正它，没有只增不减的永久巩固。该规则仍是新的工程假说，需要独立验证长期知识、污染和纠错速度。

## 验收与未执行

`v1/test_dynamics.py`覆盖：读取不写入和未来因果；固定状态尺寸；任意累积切分与逐lane提交；全部关键控制参数的非零有限梯度；P正定和相位单位范数；P/trace/动态映射/相位对输出的真实影响；Fourier/耦合/soft群对消息与输出的影响；相位关闭完整性；严格零脉冲；局部反馈一次消费和正交保护；已知延迟/越界拒绝；真实参数固化、reset后保持、冲突修正、旧版本拒绝与多会话限制。

稀疏检查验证实际节点算子执行K<N、诱导边合法、全节点view等价、inactive冻结、全局信用移槽/ID、固定state容量、共享参数梯度，以及整网任意调用切分与未来因果。

这些检查覆盖计算与机制合同。Mac/MPS短程验收记录在results/v1/中；新架构长训练、CUDA性能与稀疏吞吐对照尚未执行；外部公共任务、严格独立后验、自然语言自动延迟归因仍须另外执行。

JEPA、逐节点完整LLM、无限路径历史与Taylor逆恢复保持排除。二阶乘性项、新优化器、butterfly/公共低秩模式等是原构想允许的数学候选或独立研究支线，不把每个曾讨论的候选同时叠成默认关键路径。
