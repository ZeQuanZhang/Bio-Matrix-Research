全部 15 项评测均覆盖固定协议规定的完整划分。评测采用 [锁定协议](../evaluations/standard/protocol.json)中的 lm-evaluation-harness 任务定义和指标。WikiText 词级 PPL 与上表留出集 token 级 PPL 各自按同一指标跨模型比较。

- **Transformer 的优势集中在语言建模。** 留出集 PPL 约为 Bio 的一半，WikiText bits/byte 低约 12.4%，LAMBADA 命中 179 题，两组 Bio 各命中 3 题。三项选择题的组间差距较小，ARC-Easy 原始准确率由 Bio 静态版领先 0.76 个百分点，长度归一化后三组相差约 0.13 个百分点。
- **动态地址在本轮没有显示出稳定收益。** 100M 节点相对 Bio 静态版的留出 PPL 高约 0.18%，WikiText bits/byte 低约 0.02%，LAMBADA 命中数相同，累计更新耗时多约 3.6%。
- **质量与效率在相同 token 预算下比较。** 两组 Bio 的累计更新耗时分别为 Transformer 的 1.80 和 1.86 倍。试验只使用一个训练种子，且状态每 512 token 重置。多种子重复、等耗时对照和跨序列长程记忆仍待验证。公开任务汇总记录未提供可用于计算组间配对区间的逐题结果。
