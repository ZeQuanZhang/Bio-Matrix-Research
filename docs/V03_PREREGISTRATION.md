# Bio-Matrix v0.3 预登记

> 归档说明：本文保留写作时点的设计或状态。项目已停止v0.9后续训练；最新执行状态见[实验索引](RESULTS_INDEX.md)。公开副本不含权重与语料。

本文件在首个超参数试跑前保存。分支 `bio-matrix-v03-network-scale`；起点 `e1fc1dc`。原始首轮代码和 `results/matrix*` 不变，报告快照见 `V03_FIRST_ROUND_FINDINGS.md`，任务书完整快照见 `V03_TASK.md`。

本轮研究对象是独立的节点网络，不把首轮单个状态或独立频率坐标的结果作为扩大 N 的门槛。主指标是任务正确率与交叉熵，同步统计只作诊断。主要对比 C3−C1、C3−C2，以及 N512 与 N32 的配对差之差。主要 OOD 汇总为对象64、关系深度4、保留的 ABA 操作组合；检索/计数没有 ABA 组合，不将它们伪标为组合 OOD。最小实际收益预定2个百分点，同时报告成本、损失、逐种子差和区间。三种子是初筛；若形成关键正结论，另补53、71两个种子验证，未补齐时不作确认结论。

## 实现边界

- C1/C2/C3 共用内容更新、逐证据编码、问题GRU、学习式证据读取、稀疏内容消息和低秩动态读出。模型名为 `role_conditioned_sparse_retention_v03`，不是首轮 `linear_add` 的直接复现。
- C1 有两个活跃的非周期辅助状态，用于消息门与读出；C2 使用二维单位圆状态，内容消息和相位门保持开启，κ=0；C3 在同一内容规则上加入有界局部相位耦合。C3比C1/C2多一个活跃标量参数，不用虚假参数补数。
- 只用相位差与加权一致度，驱动不读取绝对相位。角色8维归一化随机常量。图、角色、初始相位种子分别901、902、903；与数据种子分离。图是环起点经度保持换边的无向8度稀疏图。切分图为两个同度数隔离分量，重新连线使用独立图种子1901。内部图不取自世界关系。
- 输入维128，低秩读出8，中间投影32。内容自反馈也经32维分解，减少S2宽状态的二次参数膨胀。S2仍不等参数/等MAC；逐条件公布实际差异，不能解释为全部预算同时匹配。
- 每次快照重新初始化；不宣称已实现流式持久记忆、语言模型或标准图像CLEVR。关闭二阶反应、贝叶斯相位、多频率、新优化器和动态专家。

## 数据与选择

主数据为公开代码生成的中文微型关系世界：属性检索、甲/乙关系追踪、颜色比较、集合计数、条件规则。每个episode随机重排物体ID、属性和两套关系。额外无关记录显式标记，且其ID与被问世界不交叉；必要证据从不删除。每批从M8/16/32、深度1/2/3、干扰0/.5/.8均匀选择难度，批内任务族均匀；ABA组合保留，单个原语在训练中出现。

每次2048步、有效batch16，三种子11/23/37。数据种子70000+训练种子；所有架构和N接收相同批次及顺序。训练期间检查全部世界哈希与开发/测试世界不相交，保留批次指纹与训练世界清单。开发/测试独立随机种子81003/91003，各任务六个预定切片，每切片开发12、测试24个世界。符号求解器只生成标签和校验记录，不进入模型输入。

先在N128、独立pilot数据上，每个架构分别用0.0003/0.001/0.003训练200步，候选预算相同。最小pilot开发CE选择学习率，冻结后执行主扫描。优化器统一AdamW、warmup50、余弦衰减、梯度裁剪1；每256步以开发CE选最佳检查点，同时保存最后检查点。pilot不运行最终测试，不把短程性能当主结论。

## 顺序和预算

1. P0：代码审阅、数据校验、确定性CPU测试、MPS一致性、九组短程资源剖析。首次图切分单元测试发现N32分四组无法保持8度，已改为两个分量并重新通过；该错误在正式训练之前修复。
2. P1：N32三个架构，再N128三个，再N512三个，先种子11，再23，再37，共27次完整2048步。不因N32表现取消较大规模。
3. P2：先做9次S2固定8192状态浮点数配对（d254/62/14）；18次S3训练匹配J2/8/32（N128/512×三个架构），J16引用P1；12次同度数切分/重连（N128/512×三个架构）。这批先用种子11作机制初筛，报告中标明单种子；其余种子属于尚未执行的重复验证，不能用大量测试世界代替独立训练种子。另从J16检查点做J2/8/16/32测试时改变轮数，和重训练结果分开。
4. P3：官方无图像CLEVR包，固定50,000训练问题；官方验证场景按稳定哈希分为开发/测试，记录场景/问题清单。C1/C2/C3在N128/512、种子11先配对；后续重复种子单独登记。输入真值场景图与原始问题文本；程序仅作离线校验与深度分析。名称固定为CLEVR-SG派生实验。官方英文问题保留原文，中文要求由主诊断任务满足。
5. P4/P5属于后续阶段：先比较固定8专家Top-2路由，再根据证据决定动态微专家及其他生物机制；不阻塞或混入P1。未执行时明确登记。

训练串行，MPS float32；有效batch16，剖析支持microbatch16。MPS采样driver内存超过16GiB显式中止，保留最后安全检查点，不静默改配置。支持单次运行显式墙钟预算和安全恢复。采样tensor/driver与进程RSS分开记录，不相加。实际完整执行时间优先于估计MAC；S1为等数据曝光，不是等训练时间胜利。

## 诊断与统计

主要报告全体预定切片，不依照最终测试挑选有利子集。报告每任务/M/深度、机会水平、开发集选择的多数类、问题独立与证据独立基线。因果干预从相同检查点/输入出发：共同旋转、相位交换、相位差打乱、等L2内容扰动、关闭κ、关闭消息；在最后一步之前干预与中途干预后恢复分开。节点重命名是实现不变性测试，图切分需同时比较C1/C2/C3；移除机制本身的分布偏移不替代训练匹配对照。

跨训练种子给逐种子点、均值、样本SD与t区间；仅三种子时区间不稳定。世界bootstrap若使用，独立标记，不作训练重复。只有三个N，不声称相变或普适规模律。若所有模型接近机会水平，结论是当前训练/读出尚未打通，不能否定机制。

同步记录R1/R2/R4、边余弦与边相位锁定值，仅离线少量样本。两个人为耦合群的正对照只验证动力学实现，不视为自发分群证据。状态容量、参数、训练/推理时间和性能一同报告。所有条件状态区分not_executed/running/completed/failed/aborted，原始失败记录保留。
