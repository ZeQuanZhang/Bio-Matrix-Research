# Bio-Matrix v0.3：网络规模、局部同步与动态专家的验证实验

> 归档说明：本文保留写作时点的设计或状态。项目已停止v0.9后续训练；最新执行状态见[实验索引](../RESULTS_INDEX.md)。公开副本不含权重与语料。

**交付对象：Codex／研究工程执行代理**  
**性质：新实验任务书，尚未执行；所有默认数值都是拟议配置**  
**依据：用户提供的 `FINDINGS.md` 首轮报告，以及新增的局部振荡、节点协作、动态专家构想**  
**版本日期：2026-10-21**

> 本轮主问题：当大量具有内部状态的计算节点通过局部连接相互作用时，是否出现单个状态单元实验无法检验的计算收益？这些收益能否归因于节点之间的同步协调，而非更多状态、更多参数、更多训练或更多内部迭代？
>
> 不以“小规模首先超过基线”作为进入全部规模点的前提。先完成预先登记的网络规模扫描，再判断有限实验范围内是否存在规模相关收益。同时，不用“规模还不够大”无限推迟检验结论。

## 0. 执行约定与本轮边界

在现有仓库中创建独立的 v0.3 实验目录或 Git 分支。保留首轮模型、配置、原始指标和失败记录，不覆盖已有结果。先阅读 `FINDINGS.md` 及其引用的本地代码和结果文件；文件缺失时明确记录，不能根据报告中的相对路径假装已经审计实现。

本轮交付需要包含代码、测试、真实运行记录、图表和结论。只生成方案与待办清单不构成完成。另一方面，必须把“已执行、未执行、失败、因预算中止”分别标注，不能用计划参数填充实验结果。

硬件为 M5 MacBook、24GB 统一内存。优先 PyTorch/MPS，不调用云算力，不依赖 CUDA 专用内核，不静默把完整训练转到 CPU。小型确定性数值检查可在 CPU 上完成。探测实际环境后锁定依赖版本。

本轮保留：内部状态、动态外部矩阵、局部相位耦合、任务条件路由。首个主实验暂不叠加二阶反应、EKF、贝叶斯相位和新优化器。相位耦合本身已经是非线性动力学；先识别这一新增机制的贡献，之后再检查组合收益。

## 1. 如何使用首轮报告

### 1.1 报告实际支持的结论

[F1] 的核心指标是 2/4 键、24 个干扰事件，机会水平为 25%。`linear_add` 为 74.3%，`gru_dynamic` 为 61.1%；清零与交换状态后均大致回到机会水平。报告说明没有 Attention 或 KV 缓存，干预发生在查询之前（报告第 5–19 行）。

动态读出对 GRU 的三个种子均有提高，平均为 7.36 个百分点；动态读出下加入二阶反应的三个种子均下降。跨架构参数量并未完全匹配（第 21–34 行）。

概率／频率扩展的训练条件与核心实验不同，不能直接混排。它们尚未提供稳定的额外优势；概率版本缺少关键点估计对照，周期预测短期改善未转化为长期改善（第 36–65 行）。

### 1.2 不能从首轮推导的结论

报告没有给出跨节点耦合、动态分群、稀疏专家路由或节点数量扫描的结果。因此，首轮不足以评估“集体协调在一定节点规模下发挥作用”的假设。

不能把 32 维状态解释为 32 个独立互动的神经元群体，也不能把 96 维状态与 32 个三维节点视作等价架构。必须检查它们的连接与更新方式。

本轮不撤销首轮的负结果。二阶项等机制需要在新的环境中重新接受对照，而不能因为换了任务就忽略已有证据。

### 1.3 外部研究提供的启发

AKOrN 研究了振荡单元的同步计算，并在对象发现与数独等任务中做实验，也单独研究了内部更新步数。[1] 这支持采用网络级、关系推理式测试，但不保证我们的标量相位实现能复现其结果。AKOrN 中的球面维度、通道数与本方案的节点数也不能直接对等。

已有研究讨论振荡单元与普通单元的耦合，以及由状态产生的低秩权重修正，但其演示范围有限。[2] 本方案仍需要自己的实验。

## 3. 明确定义“规模”

一个**计算节点**拥有自己的运行时状态、相位、输入响应和邻居。节点更新函数可共享参数；节点仍是不同的状态单元。

统一使用以下符号：

| 符号 | 含义 |
|---|---|
| `N` | 网络中的状态节点数 |
| `d_s` | 每个节点的内容状态维度 |
| `z_i ∈ R²` | 单位圆相位表示 `(cos θ_i, sin θ_i)` |
| `C_state = N(d_s+2)` | 内容状态与相位合计浮点数，不含其他缓存 |
| `k` | 每个节点的邻居数量 |
| `J` | 一个外部事件／一次求解中的内部演化轮数 |
| `T` | 外部输入事件数，不能与 J 混淆 |
| `E, top_k` | 固定专家数量及实际激活专家数 |
| `P_total, P_active` | 总参数量及当前样本激活参数量 |
| `M` | 数据中对象数／关系数／并行子问题数 |

主规模点：`N = 32, 128, 512`。补充规模点：`64, 256, 1024`；`2048` 为硬件剖析通过后的上限扩展点，不自动执行。

这些数值是实验采样点，没有生物学临界阈值含义。本轮不以 0.1B 参数作为必要门槛：相互作用节点的数量与可训练权重数量可以分别改变。

## 4. 核心架构：内容状态与相位协同的节点网络

### 4.1 节点的身份与初始化

每个节点有固定角色特征 `r_i`，例如根据种子生成的 8 维归一化随机向量。初始版本中 r_i 不训练，由共享投影产生节点偏好。这样增加节点不必同比增加模型参数。

角色特征、图拓扑、初始化相位均不得编码对象类别、任务标签或正确群组。独立的数据随机种子、初始化随机种子和图种子分别保存。匹配实验使用相同角色特征与图。

共享参数与相同输入可能导致所有节点行为相同，因此必须检查角色特征与初始化是否真正打破了对称性。不能靠手工把“逻辑节点”“记忆节点”等类别写入初始化来制造专门化。

### 4.2 内容状态更新

初版使用简单、数值受控的保留规则，例如：

\[
\tilde s_i^{\ell+1}=\tanh(Bu_i+D m_i^{\ell}+Rr_i+b),
\]
\[
s_i^{\ell+1}=\lambda_i^{\ell}\odot s_i^{\ell}
 +(1-\lambda_i^{\ell})\odot\tilde s_i^{\ell+1}.
\]

其中 λ∈[0,1]，u_i 为输入写入，m_i 为邻居消息。允许复用首轮简单保留模块，但若方程变化，必须赋予新模型名，不能冒称直接复现原来的 `linear_add`。

所有核心组使用相同内容状态规则。二阶乘性反应保持关闭，避免首轮已发现的训练问题混入相位实验。

### 4.3 相位更新

以标量角度表达的拟议更新为：

\[
\theta_i^{\ell+1}=\theta_i^{\ell}+\delta\left[
\omega_i+u_\theta(s_i,u_i,r_i)
+\kappa\sum_{j\in\mathcal N(i)}\bar a_{ij}^{\ell}
\sin(\theta_j^{\ell}-\theta_i^{\ell})\right].
\]

\[
a_{ij}=\tanh c_\psi(s_i,s_j,r_i,r_j),\qquad
\bar a_{ij}=\frac{a_{ij}}{\epsilon+\sum_{j\in\mathcal N(i)}|a_{ij}|}.
\]

允许正负耦合，但约束幅度。频率、输入驱动和步长均设有界参数化。初版不加随机动力噪声；随机性只用于初始化与数据，之后通过独立实验研究噪声。

实现优先保存二维实数单位向量 z_i，使用二维旋转更新，定期归一化。无需在 MPS 上依赖复数张量或频繁执行角度取模。实际数学与角度表示应在 CPU 小例子上交叉验证。

归一化的目的，是避免增加邻居数或节点数时，耦合力总量自动增大。不能把这种数值放大解释为规模效应。

### 4.4 相位必须影响实际计算

局部相位调制因子：

\[
\chi_{ij}=\frac{1+\cos(\theta_i-\theta_j)}{2}.
\]

将其用于消息传递：

\[
m_i=\sum_{j\in\mathcal N(i)}\pi_{ij}(s,u)\,\chi_{ij}\,W_m s_j.
\]

其中 π 为内容相关归一化权重。另通过节点状态汇总控制低秩读出：

\[
y=W_0h+U\left[g(S,Z,h)\odot Vh\right].
\]

不显式构造完整动态权重矩阵。所有对照使用同一输入编码器、同一基础输出头、同一低秩维度。

记录两个独立开关：`phase_to_messages` 与 `phase_to_router`。这能区分相位影响通信和影响专家选择的贡献。

仅绘制相位曲线而不让相位参与任务计算，不构成机制实验。

### 4.5 时间与因果顺序

区分外部事件 t 与内部求解轮数 ℓ。每个事件只读取已到达的信息，执行 J 次内部更新后输出。目标答案只能进入损失，不能进入状态更新器或路由器。

快照任务允许一次看到当前全部证据，专门检验集体推理；它不承担跨时间记忆结论。流式任务逐条输入证据，在查询阶段移除原始证据，仅保留状态，专门检验记忆。

默认不把完整输入序列藏入 Transformer 编码器或 KV Cache。问题文本的编码器可以读取完整的当前问题；证据记录分别编码，不经一个强大的全证据推理器预先求出答案。

## 5. 图拓扑与传播范围

默认使用固定度数 `k=8` 的连通稀疏图，图生成与任务标签独立。可采用连接性经过检查的随机正则图，或明确记录重连方式的小世界图。

使用邻居索引 `[N,k]` 和批量 gather 实现。禁止构造每步 `[B,N,N,d]` 张量。使用稠密蒙版但仍做全部 N² 乘法时，必须记作稠密计算。

规模变化时报告：度数、连通分量数、近似最短路径分布、J 轮可达节点比例。相同 J 在更大的稀疏图上可能覆盖较小的网络比例，这是必须测量的限制。

拓扑对照：

| 拓扑 | 作用 |
|---|---|
| 连通稀疏图 | 主模型 |
| 同样 N、相同度数的多个隔离子图 | 检验跨局部群体互动是否重要 |
| 度数匹配的随机重连图 | 检验具体连接结构是否重要 |
| 预先植入社区的图 | 只作“能否产生分群”的实现正对照 |

隔离子图仍可能通过共同输入和最终读出受到相似驱动，因此不把“图被切开”理解为整个模型绝对没有间接共同信息。正对照中的人工社区也不能用来宣称自组织。

## 6. 三组必须分开的规模实验

### 6.1 S1：固定单节点维度，改变节点数量

`N=32,128,512`，`d_s=16`，`k=8`，训练内部步数先固定 `J=16`。

这测试自然的网络规模扩张。总状态容量与计算同时增加，所以单独成功不足以证明集体涌现。各节点数下都训练匹配的非相位、独立振荡和耦合振荡模型。

小 N 无增益不能取消大 N 的预登记实验；出现 NaN 或无法正确传播梯度等实现故障时可以暂停修复。

### 6.2 S2：固定状态总容量，改变节点组织方式

设置 `C_state=8192` 个浮点数：

| N | 内容状态 d_s | 每节点总状态 d_s+2 | 总状态 |
|---:|---:|---:|---:|
| 32 | 254 | 256 | 8192 |
| 128 | 62 | 64 | 8192 |
| 512 | 14 | 16 | 8192 |

所有额外保留的隐藏变量、专家缓存、相位置信度都必须计入状态账本。无相位对照用额外两个实数状态补齐空间，不能只比较 d_s。

这组问：同样的状态存储量，分布在许多较小节点中，是否更适合当前任务？

改变 d_s 也会改变参数与计算。不能宣称同时自动实现等参数、等状态、等时间。另做参数匹配或低秩共享控制，并完整报告差异。维度固定方案与容量固定方案是互补证据，不是任一方案单独解决全部混杂因素。

### 6.3 S3：固定网络，改变内部交流轮数

在 N=128 和 N=512 上测试 `J=2,8,16,32`；64 轮作为外推诊断。

两种协议分别报告：

- 训练与测试 J 一致的正式比较。
- 用训练 J=16 的检查点评估更多／更少轮数的测试时计算曲线。

后者不能冒充重新训练后的最佳成绩。非振荡消息网络也获得相同迭代预算。增加 J 的耗时与 FLOPs 全部计入。

这组防止把“网络需要更多轮传播”错写成“只有更多节点才有效”。先只运行主规模的 J=16，再对选定配置扩展，禁止一开始全组合穷举。

## 7. 模型对照：必须有强通信基线

| 代号 | 模型 | 状态／消息设置 | 用途 |
|---|---|---|---|
| C0 | 独立状态节点库 | 无跨节点消息 | 集体互动的诊断下界 |
| C1 | 非振荡消息传递网络 | 同图、同状态预算、同迭代，使用学习式内容门控 | 核心强基线 |
| C2 | 独立振荡网络 | 与 C3 同样的内容通信和相位门控，相位间耦合 κ=0 | 隔离相位相互作用 |
| C3 | 局部耦合振荡网络 | 相位与内容共同演化 | 主候选 |
| C4 | 公共时钟控制 | 所有节点受同一个周期驱动，其余结构匹配 | 排除单一时钟或位置效应 |
| C5 | 无状态的标准 Transformer／MoE | 同输入、同训练数据、近似参数预算 | 外部参考，不作唯一基线 |

主扫描只跑 C1、C2、C3，避免任务数量爆炸。C0、C4、C5 在候选规模点做诊断。

C1 不是弱小的单个 GRU。它必须能在与 C3 相同的图上进行多轮消息传播，并拥有等额的内容／门控状态。用两维非周期状态替代相位坐标，保留相近的门控参数和输出结构。

C2 中关闭的是相位之间的耦合，不关闭普通内容通信。否则无法分辨相位耦合收益和任何跨节点通信收益。

对所有模型提供相同数量的超参数候选，不只细调 C3。对参数量不完全相同的成对比较，提供参数账本；不使用未参与前向计算的“假参数”凑数。

## 8. 核心任务 A：多对象关系组合推理

### 8.1 为什么更换主任务

原来的少量键值延迟检索保留为回归测试。本轮主任务要求并行维护多个对象与关系，随问题组合不同处理步骤。任务的难度来自关系组合和干扰，不依赖周期信号作为标签。

### 8.2 公开可复现的程序生成器

生成对象、属性与关系的微型世界。例如：

```text
对象 K 的颜色 = 蓝
对象 P 的颜色 = 红
关系 next(K) = P
关系 next(P) = T
对象 T 的颜色 = 绿
问题：K 的 next 的 next 的颜色是什么？
答案：绿
```

对象 ID 在每个 episode 重新置换。属性值与关系随机产生。模型不能依赖训练中固定的键值映射。

任务族包括属性检索、沿关系追踪、过滤后比较、集合计数和有限的规则组合。公开完整生成代码、版本和生成种子；它是自建诊断集，不能冒称现成标准排行榜。

默认难度轴：

- 对象数 M：8、16、32、64。
- 关系组合深度：1、2、3，4 作外推。
- 无关证据比例：0、0.5、0.8。
- 属性或关系更新：仅在流式变体加入，时间顺序明确。

主训练使用 8/16/32 对象与 1/2/3 步组合的固定混合。测试同时含训练范围及 64 对象／4 步组合。不同 N 的模型看到相同数据分布。不能让大模型自动获得更容易的数据。

实现符号求解器，只用于生成标签、验证唯一答案和检查数据，不在神经模型推理路径中调用。所有实例应有充分证据；不能通过隐去必要信息制造不可解任务。

### 8.3 两种协议

**A-snapshot，首要协议：**一次给出证据集合和当前问题，经过 J 次内部协调作答。检验多节点协作，不把结果称为持久记忆。

**A-stream，后续协议：**依次输入事实、更新与干扰，查询阶段仅保留节点状态。输入阶段每事件可用少量内部更新，查询阶段再作统一 J 次协调，全部计算计入预算。

不将数据对象关系图直接作为内部节点耦合图；两者独立。任务中的实体 ID 是可用证据，但不能据此手工把同一实体的全部证据指定为一个相位群体。

### 8.4 泛化与泄漏检查

划分按完整世界／关系图／episode，而非按同一世界的问题随机拆分。保留部分操作组合未在训练出现，但每种基本操作在训练出现。

加入问题独立、证据独立、随机答案及多数类基线。结果按任务、对象数、组合深度分别报告，避免总体均值掩盖差异。

不要强制每种任务对应一个专家，不将隐藏任务 ID 或正确对象分组送入路由器。自然问题中的操作词属于合法输入，不能在所谓“无任务 ID”测试中删除至任务不可辨认。

## 9. 外部任务 B：CLEVR 场景图组合推理

使用官方 CLEVR 的无图像数据包，包含问题、答案、场景图与程序标注。[3] 官方还提供 CoGenT 的未见属性组合设置。[4]

本轮输入采用结构化场景图与原始问题文本，不训练图像识别网络。命名为 **CLEVR-SG 派生实验**，明确获得了真值物体信息；不能与标准图像 VQA 成绩直接比较。

训练／验证问题中的功能程序只用于任务难度分析、标签校验及诊断，不能作为模型输入或直接执行求答案。场景图本身已经给出对象划分，因此本实验不能独立证明“从未分组感知特征中涌现物体绑定”。

固定一个训练子集，先建议 50,000 个问题；按场景划分开发与最终评测，防止同一场景问题跨集合泄漏。若使用官方验证集划分内部开发／测试，给出 scene ID 清单与哈希。所有模型使用同一子集。

正式目标：C1、C2、C3 在一个中等与一个较大节点规模的关系深度、计数、比较和未见组合测试。不因某模型在最终测试上好看而调整子集。

下载记录来源、许可证、文件校验和、样本清单。只下载无图像包，避免无关的大型图像下载。资源未成功取得时，标注“外部任务未验证”，不能用自建任务代替后仍声称完成外部验证。

## 10. 任务 C：共振路由与动态专家

### 10.1 先固定专家库，检验路由机制

在通过网络级正确性测试后，加入相同的 `E=8, top_k=2` 专家库。所有路由器使用同一专家结构与相同输入编码；每个尺度点的 E 不随 N 改变，避免同时扩大专家参数。

核心比较：普通内容 Top-2 路由、带 C1 状态的路由、带 C2 状态的路由、带 C3 状态的路由。

给每个专家一个学习式读出查询，汇聚节点内容以及相位一致程度。例如：

\[
\alpha_{ei}=\operatorname{softmax}_i(q_e^\top f(s_i,r_i)),\quad
\bar s_e=\sum_i\alpha_{ei}s_i,
\]
\[
R_e=\left\|\sum_i\alpha_{ei}z_i\right\|_2,\quad
\ell_e=w_e^\top[h,\bar s_e]+\beta_eR_e.
\]

再对分数 Top-2 并归一化，执行对应专家。R_e 的定义不依赖共同的绝对相位偏移。C1 提供预算匹配的非周期状态统计，而不是少一个整个门控分支。

这些专家查询是预设数量的读出模块，本实验应称为“状态／共振控制固定专家路由”，不能宣称专家本身自发生成。

训练损失、负载均衡项、温度和任何预热阶段在各路由器间一致。记录专家负载、未使用专家比例和实际执行调用数。不能先算全部专家再遮掉结果；那只能算软稠密混合。

### 10.2 随任务变化的协作模式

使用任务 A 的操作组合和任务 B 的问题类别。任务类别只用于离线分析，不能作为隐藏监督强制节点分组。

分析路由与任务的关系、相同基本操作在新组合中的复用，以及改变上下文但保留同一查询时路由是否改变。普通历史状态路由也必须得到同样测试。

### 10.3 动态节点专家群：独立的第二阶段

当固定专家路由已有可解释结果后，才实现动态微专家库。每个节点关联一个低秩计算分支，不预先固定哪些节点属于同一专家。

由内容分数选择少量锚点，再结合局部相位关系与邻接信息选择固定数量的节点组成临时计算群。初版每样本激活 16 或 32 个微专家，所有尺度固定激活数量。

同时实现：相同微专家库的普通内容 Top-K、固定分组选择、相位辅助动态分组。三者共享相同节点参数和总激活预算。

硬选择的梯度只通过实际使用的连续权重与分支传播；明确记录 Top-K 的不可微选择以及辅助训练策略。若采用软分组预热，各对照必须共享相同日程。

控制器可以更新所有轻量状态，但只有选中节点执行昂贵的外部矩阵。控制器成本必须加入总成本。稠密软分组仅用于机制验证，不能宣称获得 MoE 的运行速度优势。[5]

本阶段中 N 增大会增加微专家参数，与前面的“共享参数状态网络”不同，应在单独图表报告，不能混成同一条纯节点规模曲线。

## 11. 动力学与功能指标

### 11.1 任务指标始终是主指标

至少记录：逐任务准确率、交叉熵／正确答案对数概率、组合深度曲线、对象数曲线、样本效率、训练耗时与推理延迟。

机会水平按新任务的类别分布计算，不能沿用首轮的 25%。计数类和不均衡标签还要报告多数类基线。

同时保留连续指标和离散准确率。不要只在准确率突然越过某个阈值时宣称涌现；指标选择本身可能造成表面上的突变。[6]

### 11.2 同步诊断

全局一阶同步度：

\[
R_1=\left|N^{-1}\sum_i e^{\mathrm{i}\theta_i}\right|.
\]

另记录二阶／四阶序参量 R₂、R₄、图边相位差、局部一致度和固定时间窗的相位锁定值：

\[
\mathrm{PLV}_{ij}=\left|J_w^{-1}\sum_{\ell\in\mathrm{window}}
 e^{\mathrm{i}(\theta_i^\ell-\theta_j^\ell)}\right|.
\]

高 PLV 也可能代表稳定的反相或非零相位差；R₁ 很低也可能对应多个平衡的同步群。相同频率、共同输入同样可能产生表面一致，所以要和 C2、C4 对照。

全局同步度不作为默认训练目标。强行奖励所有节点同相可能只获得一个坍缩群。分群规则和阈值用开发集／无标签动力学预先固定，不根据测试标签调整。

大 N 时只记录图边与固定采样节点对的统计；不要在每个训练步构造完整 N² 诊断矩阵。热力图在离线少量样本上生成。

### 11.3 功能分化的测量

离线统计每个专家／节点对任务类别的选择性、不同任务路由分布的相似度、组合任务对已有节点的复用，以及跨样本模式的重现性。

内部节点组标签与样本任务标签不在同一个索引空间，不能直接对二者计算 ARI/NMI。只有明确构建了同一组对象上的两个聚类，才使用这些指标。例如对“样本的路由特征”聚类后，与样本任务类别比较；这仍然只是关联证据。

若比较跨次运行的节点分群，使用对节点重命名不敏感的比较方法。动态重组不要求每种任务有唯一且固定的节点集合。

## 12. 因果干预：不能只做相位打乱

所有干预从同一检查点与同一输入出发，记录立即影响和恢复若干轮后的影响。不要使用测试标签选择破坏哪些节点。

| 干预 | 保留什么 | 要检查什么 |
|---|---|---|
| 共同相位旋转 θ_i←θ_i+c | 全部相位差 | 依赖相位差的实现应近似保持输出不变 |
| 只交换节点的相位、不交换内容 | 相位分布、内容分布 | 相位与内容的对应关系是否重要 |
| 打乱相位差 | 参数、内容状态 | 相位关系破坏的影响 |
| 等能量内容状态扰动 | 相似的扰动强度 | 排除任意内部破坏都会掉分 |
| 仅关闭相位耦合 κ | 内容通信、原始图 | 相位相互作用的作用 |
| 同度数切分／重连图 | 状态量、边数 | 连接组织方式的作用 |
| 固定当前路由 | 专家参数 | 路由动态变化是否重要 |
| 节点名称、状态、图、角色和关联参数一起置换 | 完整函数关系 | 检查代码是否错误依赖索引 |

共同相位旋转仅在没有外部绝对相位锚、读出仅用相对相位／一致度时具有不变性。本方案默认满足该设计；若修改了架构，必须同步修改该测试预期。

测试时去掉训练中依赖的机制会产生分布偏移，因此还必须训练匹配的无耦合基线 C2。性能在干预下下降不单独证明同步优于其他计算。

节点“专门化消融”需要先用开发集确定选择性节点，再在独立测试集上移除；比较相同数量、相近活动幅度／度数的随机节点。不能事后挑一组破坏效果最好的节点来支持脑区类比。

## 13. 如何检验“节点形成规模后才发挥作用”

先规定主对照，例如 C3 对 C1，定义：

\[
\Delta(N)=\mathrm{Score}_{C3}(N)-\mathrm{Score}_{C1}(N).
\]

再计算规模交互：

\[
I=\Delta(N_{large})-\Delta(N_{small}).
\]

同时报告 C3 对 C2 的对应结果。C3 相对于弱基线提高，而不超过 C1／C2，不足以支持独特的相位耦合收益。

结果解释：

| 观察 | 允许的解释 |
|---|---|
| 所有方法随 N 近似同步变好 | 通用的容量或计算增长 |
| C3 在大 N 扩大相对优势 | 支持测试范围内的规模相关增益 |
| 固定状态总容量后优势消失 | 状态容量可能解释主要收益 |
| 非振荡消息传递达到同样收益 | 目前主要证据支持通信，未支持相位机制独特价值 |
| 增加 J 即改善，小 N 也有效 | 更多内部计算／传播可能更关键 |
| 图切分破坏 C3 的优势，但普通图网络同样受损 | 跨节点协作重要，仍未独立定位相位机制 |
| 局部群体清晰，但任务无提升 | 观察到了动力学现象，未得到任务收益 |
| 参数增长后提升、等时间表现更差 | 存在容量收益与效率代价，需要 Pareto 分析 |
| 全部方法都近机会水平 | 任务或训练未打通，不能据此否定机制 |
| 全部接近满分 | 缺少区分度，需在预登记的更难切片上评估 |

使用配对随机种子、相同评测实例、相同数据顺序。至少报告逐种子差值、均值、标准差和置信区间。初筛三个种子；关键结论至少五个独立种子复测。

不把同一训练检查点的几千个问题当成几千次独立模型训练。可做按世界／场景分层的样本 bootstrap，但与跨训练种子的变异分开报告。种子少时区间不稳定，明确标注。

如果拟合 Score~log₂N 与架构交互，作为探索性趋势分析。三个节点规模点不足以宣布严格的相变或普适尺度律。若出现疑似拐点，用预留的 64/256 等中间规模和新的种子验证。

预登记最小实际收益，例如主要 OOD 切片相对核心基线提高 2 个百分点，同时报告连续损失与成本；这是本项目的决策阈值，可在正式实验前修改一次并记录，不能当作普遍科学标准。

## 14. 计算预算、公平性与 MPS 工程

### 14.1 三套比较分开报告

1. **等数据曝光：**相同训练样本、有效 batch、数据顺序和曝光次数。
2. **等计算或等实际训练时间：**记录完整节点更新、编码、路由和专家计算；不可只计激活 FFN。
3. **相近参数／相同状态：**通过专门配置匹配，而非假定同 d_s 就公平。

不能同时精确满足全部条件时，报告实际差异。报告准确率—耗时、准确率—状态量、准确率—参数量的 Pareto 曲线。

### 14.3 硬件剖析

先预热，再测稳定区间。MPS 在计时边界同步，避免把异步提交时间误写为执行时间。分别记录训练步、评测、数据处理、保存检查点的时间。

官方 MPS 接口区分张量当前分配量与驱动分配量，后者包括缓存等；不能相加当成总内存。[7] 记录进程 RSS 和 MPS 内存采样值，并注明采样峰值可能遗漏瞬时峰值。

N=512、d_s=16 的**当前状态**只有 512×18 个浮点数，但反向传播需要保存大量中间量。不得用当前状态大小宣称整场训练内存安全。

内存不足时按顺序：减小 micro-batch 并梯度累积、采用验证过的重计算、减少离线诊断频率。不能静默删掉状态或内部轮数后，仍把结果标成原配置。流式训练采用截断反向传播时，所有对照共享截断长度并明确跨截断保留了什么。

不要预先许诺 512／1024／2048 节点的训练速度。以剖析日志决定可执行上限。操作不兼容时记录具体算子，不隐藏 CPU 回退。

## 15. 分阶段运行，避免组合爆炸

### P0：代码审计、数值检查与数据校验

读取已有实现，保存首轮报告快照。验证数据生成器、节点独立状态、邻居索引、正向与反向梯度、单位圆约束、共同相位旋转不变性、动态矩阵分解等价性和无未来标签泄漏。

用人为双群耦合系统检查动力学实现能工作；它仅是正对照。再做 C1/C2/C3 在 N=32、128、512 的短程剖析。短程结果只用于排错和资源规划，不作为科学胜负。

### P1：网络级主规模扫描

在任务 A-snapshot 上训练 C1/C2/C3，N=32/128/512，三个种子，共 27 个预登记主运行。采用相同混合训练数据、开发集规则和曝光预算。

可先执行每个规模的一组配对运行检查流程，随后补齐种子。不得只跑最小规模，再以负结果取消其余点。

### P2：区分容量、交流轮数与拓扑

在 P1 最有判别力的任务切片上补：固定总状态容量 S2、内部轮数 S3、同度数隔离／重连图。切片选择依据开发集并记录；最终报告同时展示所有已跑切片，不能只保留有利结果。

关键对比至少五种子。先选核心对照与候选，不把全部图拓扑、节点数、步数、学习率作全笛卡尔积。

### P3：公开外部任务

固定方案后，在 CLEVR-SG 运行 C1/C2/C3 的中等和较大规模。公开任务失败也保留；若自建集成功而公开集不成功，结论限于诊断任务。

### P4：固定专家路由

加入固定 MoE 专家库，比较普通、非振荡状态、独立振荡、耦合振荡路由。检验收益是否在真正稀疏执行下仍然存在。

### P5：动态微专家与完整生物机制

根据前四阶段证据决定是否展开动态节点专家群。随后才在选定规模追加二阶反应、概率相位和多频率分支的独立消融，不改变主结果的身份。

不要让 P5 的实现阻塞 P1。若执行预算有限，优先交付 P1 的完整规模配对与真实资源记录；在报告中明确 P2–P5 的未完成状态。

## 16. 暂缓模块如何重新进入实验

### 16.1 二阶反应

仅在相同节点图、读出、相位、参数预算上开关二阶项。先检查饱和比例、反应项／线性项幅度与多步梯度，再判断是否提高任务分数。不能以更大网络自动抵消首轮负结果。

### 16.2 贝叶斯相位或不确定性

角度具有周期性。采用二维圆周表示或适当的圆周分布；不直接把跨 −π/π 的角度差当作普通欧氏距离。必须同时保留同观测网络的点估计对照、等状态容量对照与校准评测。

概率模块只在含噪观测与规则变化任务中测试增益，不把“方差变量变大”解释为模型理解知识可靠性。

### 16.3 多频率

为每个节点增加频率时，按新增状态量补齐非振荡对照。分别测试周期与非周期任务。主结论不得来自只对频率架构有天然优势的正弦预测。

### 16.4 优化器

## 18. 允许给出的最终结论

报告末尾按证据选择结论，可同时选择多个：

**A. 支持网络协作，但未支持相位独特性。** 多节点消息交换优于独立状态库，普通消息网络也达到同样表现。

**B. 支持测试范围内的相位耦合收益。** 匹配的内容通信和独立振荡基线无法解释全部增益，训练与干预证据相互支持。

**C. 支持规模相关增益。** 大 N 的相对收益可重复扩大，并经过状态量、内部迭代、参数与计算控制；仅针对已测任务和范围成立。

**D. 支持功能性收益，但尚无效率优势。** 相同数据下提高，而等时间或同推理成本下未优于基线。

**E. 只观察到同步现象。** 分群或节律出现，但未改善任务能力。

**F. 在本轮范围内未检出优势。** 明确报告最大 N、J、训练预算和统计不确定性，不能外推到所有更大规模，也不能用未测试的大规模无限保护假设。

**G. 实验尚无判别力。** 训练失败、全体天花板／地板效应、设备约束或样本不足使结果无法回答问题。

不把任务相关路由称为真实大脑功能区，不把局部同步称为通用智能，不把固定专家路由说成自组织专家。任何更强表述都需要新的直接证据。
