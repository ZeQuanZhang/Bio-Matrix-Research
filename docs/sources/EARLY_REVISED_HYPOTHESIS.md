## 2. 研究背景与核心假设

我们希望探索一种新的神经计算单元。

传统人工神经元通常通过固定权重计算输出：

```text
输入信号
   ↓
加权求和
   ↓
激活函数
   ↓
向多个下游节点传播
```

虽然不同连接具有独立权重，但在普通推理阶段，这些权重通常不根据历史活动发生持续变化。

我们的灵感来自生物神经系统：

1. 一个神经元可以同时影响多个下游神经元。
2. 不同连接的有效信号传递强度不同。
3. 突触传递会受到内部生化状态及近期活动历史影响。
4. 生化反应网络可以存在稳定、亚稳定或周期性的内部状态。
5. 记忆可以理解为系统内部状态对历史信息的保留。
6. 生物反应规律不是每次输入时随机生成的；相对稳定的反应机制是在演化过程中形成的。
7. 我们可以借助梯度训练模拟这种长期的机制优化，同时让短期内部状态在运行时持续变化。

核心研究假设：

**让一个神经计算单元拥有有限维非线性内部状态，并由内部状态动态调制外部计算矩阵，可能提高网络的关联记忆、状态保持、抗干扰和数据利用效率。**

进一步假设：

引入贝叶斯先验/后验更新、频率动力学及多时间尺度状态，可能改善模型对信息的选择性保留与更新。

这些都是待验证假设。

## 3. 总体架构：Bio-Matrix

采用两个相互配合的系统。

### 3.1 内部状态系统

每个计算模块保留内部状态：

`s_t ∈ R^r`

其中 `r` 是较小的状态维度，例如 16 或 32。

内部状态按照确定的、经过训练的非线性动力学规则演化：

```text
z_t = tanh(
    A @ s_t
    + B @ x_t
    + R @ ((P @ s_t) * (Q @ s_t))
)

alpha_t = sigmoid(C @ x_t + D @ s_t + b)

s_(t+1) =
    (1 - alpha_t) * s_t
    + alpha_t * z_t
```

说明：

- A：内部状态相互作用
- B：输入驱动
- P、Q、R：低秩非线性乘性反应
- alpha：状态更新门控
- s：跨时间步持续保存的内部状态

矩阵参数通过训练优化，不能每次推理随机重置。

内部状态需要支持：

- 写入
- 保持
- 更新
- 遗忘
- 检索
- 序列间隔离

第一版不需要严格模拟真实化学计量关系。请明确称其为生物启发的动力学近似。

### 3.2 外部计算矩阵

保留成熟的矩阵计算形式：

```text
y_t = W0 @ x_t
```

加入由内部状态控制的低秩动态修正：

```text
gate_t = sigmoid(H @ s_t)

y_t = W0 @ x_t
      + U @ (gate_t * (V @ x_t))
```

对应的概念性有效矩阵：

```text
W_eff(t) = W0 + U @ diag(gate_t) @ V
```

注意：

- 实现时不要显式构造完整 W_eff。
- 使用分解后的矩阵乘法。
- 基础矩阵 W0 在正常推理中保持不变。
- 内部状态决定每次信号传递的动态修正。
- 相同输入经过不同历史状态，应当能够产生不同输出。

需要明确状态更新与输出读取的先后顺序，避免当前或未来标签信息泄漏。

## 4. 实验 A：内部记忆与矩阵调制

这是今晚的最高优先级。

### 4.1 实验目标

验证动态内部状态是否真正承担了记忆功能，以及非线性状态是否相比普通循环状态具有额外收益。

采用合成关联记忆任务。

例子：

```text
WRITE A 7
WRITE B 3
WRITE C 9

DISTRACTOR ...
DISTRACTOR ...

QUERY B

TARGET 3
```

训练数据在程序中生成，固定随机种子。

禁止通过以下方式作弊：

- 把正确答案直接传入查询阶段。
- 在查询阶段重新提供完整写入序列。
- 让一个隐藏的 Attention 或 KV Cache 保存所有写入信息，却声称是 Bio-Matrix 的内部状态在记忆。
- 让训练集与验证集共享可被直接记住的固定键值映射。

必须提供仅依靠递推状态完成查询的实验设置。

### 4.2 对照模型

至少实现：

| 编号 | 模型 | 研究目的 |
|---|---|---|
| A0 | GRU | 成熟的动态状态基线 |
| A1 | Linear Gated State | 简单线性门控状态更新 |
| A2 | Nonlinear State | 引入非线性内部反应 |
| A3 | Bio-Matrix | 非线性状态 + 动态外部矩阵 |
| A4 | Bio-Matrix + Bayesian | 加入概率状态估计 |
| A5 | Bio-Matrix + Fourier | 加入频率动力学 |
| A6 | Bio-Matrix Full | 组合完整机制 |

优先实现 A0～A3，确认这些实验成立后再进行 A4～A6。

尽量保证模型参数量可比。对无法完全匹配的模型，明确报告参数量、状态容量、计算量和耗时。

特别注意：GRU 本来就具有内部记忆。必须证明 Bio-Matrix 的收益来自更好的机制，而不只是它额外增加了参数或状态容量。

### 4.3 测试维度

生成多种难度：

- 不同键值对数量
- 不同干扰 Token 长度
- 不同查询延迟
- 相同键的重复写入与覆盖
- 多次连续查询
- 超出训练长度的测试
- 不同随机种子

至少输出：

- 准确率
- Cross Entropy Loss
- 训练收敛曲线
- 状态重置后的准确率
- 状态跨样本交换后的准确率
- 参数数量
- 峰值内存
- 实际训练耗时
- Tokens/s 或 Steps/s

状态重置和状态交换应当作为独立干预，而非正常测试流程的一部分。

## 5. 实验 B：贝叶斯状态更新

这个实验用于测试“不确定性是否改善内部记忆”。

只对低维内部状态维护概率表示，不对整个语言模型权重维护完整概率后验。

建议先采用对角高斯近似：

```text
s_t ~ N(mu_t, diag(var_t))
```

内部状态经过：

```text
先验预测
    ↓
获得新观测
    ↓
计算更新增益
    ↓
后验修正
    ↓
动态矩阵调制
```

如果采用卡尔曼式计算，必须保证方差为正、维度正确，并明确其线性高斯假设或近似条件。

不能简单将 sigmoid 门控命名为 Bayesian Update。

与不维护不确定性的版本对照，观察：

- 噪声输入下的记忆准确率
- 矛盾信息覆盖能力
- 新信息写入效率
- 对错误观测的敏感性
- 计算开销

如果贝叶斯模块没有带来收益，必须如实报告。

## 6. 实验 C：傅里叶状态与多时间尺度记忆

内部状态可以包含振荡模式：

```text
s_(t+1) = A(omega, rho) @ s_t
```

其中二维旋转矩阵：

```text
A = rho * [
    [cos(omega), -sin(omega)],
    [sin(omega),  cos(omega)]
]
```

不同频率表示不同时间尺度的动态变化。

设计多个频率组，允许频率和衰减参数训练，但需要限制数值范围。

要求：

- 保留非振荡状态对照。
- 比较固定频率和可学习频率。
- 测试周期信息预测。
- 测试非周期关联记忆。
- 测试长时间延迟后的记忆保持。

不能因为傅里叶模块在正弦预测上表现良好，就得出它改善了通用语言记忆的结论。

## 7. 实验 D：训练优化器研究

这部分与前面的模型架构实验严格分开。

研究假设：

**利用训练历史的概率估计与频率控制，可能改善梯度更新的稳定性和搜索效率。**

保持模型架构固定，比较：

- AdamW
- AdamW + Cosine Scheduler
- 简化的贝叶斯梯度状态估计
- 贝叶斯梯度状态估计 + 自适应周期探索

可以使用低维梯度子空间，避免在完整参数空间维护昂贵协方差。

优先使用标准解析测试函数：

- Rosenbrock
- Rastrigin
- Ackley

记录：

- 达到目标损失的成功率
- 收敛步数
- 函数/梯度计算次数
- 最终损失
- 多随机种子的均值和标准差
- 实际计算时间

然后在一个小型神经网络上进行验证。

必须保证优化器使用相同的初始化和可比的计算预算。

特别注意：

- 不保证找到全局最优。
- 傅里叶周期探索不等于直接理解损失曲面。
- 不得把优化器改进与 Bio-Matrix 架构改进混为一谈。

## 13. 成功判定标准

今晚不要求证明 Bio-Matrix 优于现代大型 Transformer。

但至少要回答以下四个问题：

**Q1：内部状态是否真的形成了可检索记忆？**

判断标准：保留状态时能够检索，清除或打乱状态后表现明显下降。

**Q2：非线性内部反应是否优于简单的线性门控状态？**

在相同训练与评测配置下比较。

**Q3：状态调制外部计算矩阵是否优于简单增加隐藏层或 GRU？**

需要控制参数量和状态容量。

**Q4：贝叶斯与傅里叶机制是否各自产生额外收益？**

不能以整体模型的一次提升替代消融实验。

如实验结果不足以回答某个问题，必须明确标记为“尚未验证”。
