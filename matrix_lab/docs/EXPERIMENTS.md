# 预设实验协议

> 归档说明：本文保留写作时点的设计或状态。项目已停止v0.9后续训练；最新执行状态见[实验索引](../../docs/RESULTS_INDEX.md)。公开副本不含权重与语料。

主指标在正式训练前确定：2键延迟24事件与4键延迟24事件的准确率/交叉熵等权平均。
理论机会正确率25%；标签为独立随机赋值，键和值不存在跨样本固定映射。

## 数据

每条样本随机选取不同的键，并分别赋予0到3的随机值。
先写入，再插入带随机键值的干扰事件，最后查询其中一个已写入键。
部分样本重新写入一个键，答案以最后一次写入为准；部分样本连续查询两次，中间有三次干扰。
每个时间步为一个三字段事件，吞吐按事件计，不冒充自然语言Token/s。

训练数据由numpy随机数按固定种子生成，各模型同种子获得相同事件与标签。
每批记录内容摘要，最终对整个训练日程取SHA256，聚合时断言一致。
验证与测试使用固定、独立的随机数流，不从训练流抽取。
编码器不接收标签。查询没有值，模型不接收原始历史的重放或外部答案。

## 优化与选择

7种模型×3种子（42/137/2026），每次4000步、批量64，状态32维、输入32维。
AdamW，学习率0.003，50步预热，余弦衰减至20%，weight decay 0.0001，梯度裁剪1。
固定课程：前100步1键/延迟0-4；100-299步1-2键/延迟0-12；其后1-4键/延迟0-24。
25%批次覆盖写入，25%批次连续查询2次。
每500步验证，在1键无延迟、2键延迟12、4键延迟24上按平均CE选择最优权重。
测试集不选模型、不调学习率。固定预算不保证所有模型收敛。

## 测试

每项512条独立样本：1/2/4键无延迟，2/4键延迟24，2键延迟64，4键延迟128，
6/8键延迟24，3键覆盖写入，3键连续查询4次。
训练外难度均标注为外推，4次查询按每个episode的查询平均统计，避免把相关查询当独立样本。

每种条件独立运行：正常保留；每次查询前清零；每次查询前在当前批内滚动交换状态。
干预不用于训练。查询仍正常更新状态，然后输出分类；只改变查询之前的历史状态。
主指标、全部难度、每个种子、参数和成本均保留。无中途按测试结果改变课程或预算。

## 比较范围

同一状态机制比较Add与Dynamic，检查读出作用；同一读出比较Gated与Reaction，检查二阶项。
Gated与Linear的差异包含状态反馈与状态依赖门控；不能仅把它归因于二阶乘性反应。
GRU具有更大的循环参数量，Linear更少；因此这是相同状态容量/事件预算下的比较，
尚不是严格等参数或等时间实验。MAC估计不包括完整训练FLOPs。

## 概率与频率扩展的独立协议

8个版本×3种子，每次2000步、批量64：32/64/96维普通Reaction，
32维均值+32维方差，32维反应+32维零/固定/可学频率，以及96维完整组合。
不直接拿它们与4000步的核心实验排序。

75%正常事件沿用核心课程；25%为重复有噪声观测：1-3个随机键、每键3次观测、
每次有20%概率替换为其他值，目标是固定潜在真值。正常覆盖任务目标仍是最后写入。
序列开头使用不含答案的模式标记（干扰操作、缺失键、正常/噪声模式值）区分两种任务。
每个版本获得相同训练事件和随机噪声。验证包含正常2键延迟12、4键延迟24和噪声2键。
测试包括完整正常条件，加0/20%/35%观测噪声及每键5次观测的外推。
所有条件都运行保留、清零、交换状态干预。
每项256条，验证每项128条，按平均验证CE选择检查点。

## 周期机制的独立协议

零、固定、可学频率3种状态×3种子，各1000步、批量64，所有状态32维。
观察16个带少量高斯噪声的正弦值，随后不给真实数值，只输入缺失标记，预测16步。
训练频率为0.08/0.17/0.31弧度每步，随机相位和幅度；测试包含16步、64步、
未见频率0.12/0.25、较强观测噪声。比较保留和在预测开始前清零状态的MSE。
按独立验证MSE选点。周期任务即使成功，也不作为语言或非周期记忆优势的证据。

## 优化器的独立协议

2维Rosenbrock/Rastrigin/Ackley，各10种子，2000次梯度与2001次函数计算。
所有方法相同初始点，AdamW的weight decay设为0避免给解析函数引入额外目标。
固定学习率、余弦学习率、余弦+高斯梯度滤波、余弦+滤波+周期探索。
成功阈值分别为0.001/0.001/0.01，报告最终与最好损失、首次成功步数和完整采样轨迹。
再在2→32→2的固定MLP上比较同4个方法，3种子，1000步，固定XOR符号分类数据和批次顺序。
这些极小CPU任务明确使用CPU；不影响架构实验要求使用MPS的设置。
